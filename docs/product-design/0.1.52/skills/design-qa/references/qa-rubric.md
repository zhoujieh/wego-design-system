# QA 评分标准

使用此评分标准进行综合的设计到实现 QA。

## 保真度

- 布局：框架大小、网格、对齐、内容顺序、空间分组、卡片圆角、高度、边框。
- 间距：页面边距、区块间距、项目间距、内边距、点击目标间距、垂直节奏、拥挤文本、折叠区块和密度漂移。
- 排版：字体族名、字重、字号、行高、字距、换行、截断、层级、文本密度、光学平衡和不匹配的显示/正文处理。
- 颜色：Token 映射、对比度、品牌调色板、状态色、渐变、不透明度、阴影。
- 图像：所有目标图片素材均已对应，并匹配主题准确性、裁剪、宽高比、生成/真实图片质量、背景处理。
- 图标：所有图标均已对应，并匹配描边粗细、大小、风格族、对齐、光学平衡、状态变化。
- 形状和表面：圆角卡片、边框、分隔线、阴影、填充和容器处理与目标匹配，而非通用组件默认值。
- 响应式：元素不会重叠、塌陷到相邻区域、裁剪、尴尬换行或在桌面、平板和移动视口上破坏层级。
- 实现捷径：当自定义 CSS 绘制、内联 SVG 替代品、占位头像、装饰性色块和虚假产品图片偏离目标设计时，将其标记出来。

## 强制对比检查项

不要依赖泛泛的“看起来差不多”的判断。对于每次设计 QA 轮次，检查并报告以下区域：

### 核心设计与功能

- 字体和排版：识别不匹配的字体族名/后备字体、字重、缩放、行高、字距、抗锯齿、文本层级、换行、截断、显示与正文的光学处理、拥挤文本，以及文本间距使 UI 感觉损坏或更难扫描的地方。
- 间距和布局：对比框架/裁剪、对齐、边距、内边距、间距、组件大小、圆角、高度、边框和垂直节奏。指出间距漂移改变层级、密度、可读性或导致元素碰撞的地方。
- 视口韧性：检查桌面、平板和移动端宽度下的重叠元素、裁剪内容、塌陷区域、损坏网格、尴尬换行和变得不可用的控件。
- 颜色和 Token：对比调色板、渐变、不透明度、阴影、对比度、语义状态色、禁用/激活状态，以及实现 Token 是否映射到设计意图。
- 图片质量和素材保真度：检查主题匹配、裁剪、缩放、宽高比、清晰度、压缩、透明/遮罩瑕疵、光晕、背景融合和栅格与矢量适用性。禁止用 Div/CSS 绘制或自定义 SVG 绘制替代目标设计中的图片。
- 文案和内容：对于作为应用一部分（非动态内容）的任何文案，检查其是否连贯、在应用独立上下文中有意义，并且视觉上令人愉悦。
- 图标：放大并分析所有可见图标以及隐藏在控件/交互背后的图标，确保它们已完全实现、对齐且视觉上保持一致。
- 状态和交互：展开/折叠侧边栏、工具提示、表单、悬停、聚焦、激活、选中、禁用、加载中、成功、错误、空状态，以及功能前端所需的任何交互控件。
- AI 捷径产物：标记通用圆角卡片、不必要的边框、装饰性 CSS 色块、虚假 SVG 插画、半成品头像、不匹配的 Hero 图，以及在目标要求真实图像、真实图标或不同表面处理时使用自定义 CSS/SVG 替代品的情况。

### 可访问性

- 对比度、焦点指示器、键盘可达性、语义控件、标签、替代文本、减弱动效。
- 文本缩放和缩放韧性。
- 实际移动端尺寸的点击目标。
- 当文本换行、缩放或出现在更长的真实字符串中时的布局稳定性。

## 发现质量

一个有用的发现包含：

- 一个具体的不匹配或缺陷。
- 设计证据和实现证据。
- 用户或保真度影响。
- 具体修复，最好附带文件/组件/Token/CSS 指导。
- 基于用户影响的严重程度，而非个人品味。
- 相关时受影响的保真度表面：字体、间距、颜色、图片质量、布局、行为、可访问性、内容、图标或响应式。
- 拥挤文本、损坏的换行、不匹配的字重、糟糕的行高或尴尬的字距，当它们影响可读性或层级时。
- 重叠、裁剪、塌陷到附近区域或在不同视口大小下损坏的元素。
- 实现中出现但目标中不存在的圆角卡片、边框、阴影或容器处理。
- 损坏的图标、自定义 SVG、粗糙的头像尝试、Hero 图不匹配、自定义 CSS 绘制和看起来像占位符的生成素材。
- 溢出文本、拥挤文本、损坏布局、缺失状态和不完整交互。

避免：

- 模糊表述，例如“让它更精致”。
- 批评已知的占位内容，除非它影响设计目标。
- 当设计意图得以保留时，将每个像素差异都视为 bug。
- 将多个不相关的缺陷混合到一个发现中。
