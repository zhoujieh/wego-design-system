# 现有应用或网站编辑

仅在直接编辑现有本地应用或网站时使用此文件。

1. 在修改之前检查运行中的应用和源代码。
2. 当存在本地 `AGENTS.md` 或任何等效的本地设计说明时，遵循它们。
3. 优先使用现有代码库的设计系统：Token、样式变量、组件、布局模式和交互模式。
4. 尽可能复用现有的布局和组件。
5. 使用用户在实践中期望看到的真实模拟数据。
6. 当持久的设计决策应指导未来编辑时，将其记录在 `AGENTS.md` 或本地设计说明中。

不要：

- 当现有应用已有设计系统时，不要发明新的设计系统
- 除非用户要求重新设计，否则不要替换应用结构
- 不要为了填充 UI 而添加虚构的功能
- 不要使用文本、标点符号、表情符号、CSS 形状、占位框或手工 SVG 作为资产或图标的替代品
