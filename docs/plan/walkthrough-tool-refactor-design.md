## 1. 元素拖拽换位

### 1.1 交互流程

```
走查模式 → 单击选中元素 A（样式面板打开）
  → 按住 A 直接拖动（取消 500ms 定住触发；_startLongPressDrag 改为 pointerdown 即进入待拖拽态）
  → A 实时跟手（transform 位移），位移 clamp 在父容器 content box 内
  → 拖动中实时检测：A 的中心点是否越过同容器兄弟 B 的中心点（row 看水平 / column 看垂直）
     ├─ 越过 → 触发换位：A、B 交换 DOM 位置 + FLIP 动画，A 继续跟手
     └─ 未越过 → 仅位移
  → 松手：位移 + 换位顺序合并为一次变更记录（撤销整体还原）
```

### 1.2 触发判定

- **进入拖拽**：`pointerdown` 时若 `state.selectedElement === e.target 命中元素` 且非滑动意图，立即进入拖拽（无定时器）。未选中元素时保持原选中逻辑。
- **换位判定**：沿容器主轴方向，A 中心点与兄弟 B 中心点比较；A 越过 B 中心点（水平 row / 垂直 column）即触发与 B 换位。
- **防抖**：换位触发后 250ms 锁（对齐 Liaison `swapping` 锁），避免抖动重复换位。

### 1.3 DOM 排序（对齐 Liaison）

- 换位 = insertBefore 三节点交换（A、B 互换 DOM 位置），不改其余元素顺序。
- 仅同容器兄弟间换位；元素为唯一子元素 / SVG 子元素不参与换位（仅位移）。

### 1.4 FLIP 动画（参考 Figma）

- First：记录参与换位元素当前位置 → DOM 交换 → Last：记录终位置 → Invert：transform 反拽回原位 → Play：移除反拽，CSS transition 平滑过渡（200-300ms，弹性缓动）。
- 被让位的兄弟元素同样参与 FLIP，整体流动。

### 1.5 位移范围限制

- 拖拽位移 clamp 在父容器 **content box**（padding 内）边界内，无法拖出容器。
- 父容器可滚动时限制在完整内容区；拖拽中不触发容器滚动（touch-action + preventDefault）。
- 边界用父容器 `getBoundingClientRect()` 实时计算（父容器有 transform/滚动时仍准确）。
- **元素大于容器**：以元素**左上角为锚点**限制不越界（元素本体可部分超出，避免大元素无法拖动）。
- 换位后位移同样受容器边界限制。

### 1.6 共享元素同步

- 共享元素开启：所有匹配同一稳定选择器的同类元素**实时同步位移**；换位时同类元素在各容器内执行**相同换位动作**（无对应兄弟则跳过）。
- 松手统一提交为一次变更记录。
- 共享关闭：仅当前元素。

### 1.7 数据模型（变更记录）

```js
// 位移（复用现有 transform 变更）
{ selector, property: 'transform', oldValue, newValue, el, shared }

// 换位（新增 reorder 类型）
{
  type: 'reorder',
  container: '<稳定选择器>',          // 父容器
  order: ['<selA>', '<selB>', ...],   // 容器内完整顺序快照（稳定选择器）
  oldOrder: ['<selB>', '<selA>', ...] // 原顺序（撤销用）
}
```

- 一次拖拽（位移 + N 次换位）合并为**一条变更记录**。
- 持久化：加载场景 / 路由切换后按 `order` 重放（渲染完成后执行）。
- 撤销/重做：恢复 `oldOrder` 顺序 + 还原 transform。

### 1.8 边缘场景

1. 拖到 body/html/不可换位容器 → 不换位，仅位移。
2. 唯一子元素 / SVG 子元素 → 不参与换位。
3. 拖拽中阻止页面滚动。
4. 松手无位移无换位 → 还原，不进变更。
5. 动态列表刷新 → 渲染完成后重放 reorder。
6. flex-wrap / grid 容器 → 中心点越过判定跨行/列有效。
7. 容器 padding 变化 → 边界实时重算。
8. 拖拽中选中的元素被换位 → 跟随移动，不丢选中。

## 2. 数值字段拖动调值

### 2.1 交互

- 按住数值字段水平拖动调值：**向右增、向左减**。
- 步长：**整数字段 = 1，非整数字段 = 8**（位移→步数 floor/ceil）。
- 修饰键：**Shift ×5 加速**、**Alt 微调（步长 ÷8）**。
- 实时预览：拖动中元素即时更新（不进撤销栈）；松手统一提交一次。
- 点击自动全选（`select()`），直接输入覆盖。
- 去掉 focus 视觉状态（无焦点框/outline），聚焦仅体现为全选。
- 桌面端按住光标 `ew-resize`；移动端无特殊提示。
- 键盘 ↑/↓ ±1 微调保留（现有）。

### 2.2 方向判定（移动端辅助）

- 按住后先判方向：水平 >8px 锁定为调值并锁定轴；垂直 >8px 判为滚动面板。
- 锁定后不再切换意图。

### 2.3 覆盖字段

定位 top/left/right/bottom、尺寸 width/height、间距 margin/padding、字号 fontSize、圆角 borderRadius、行高 lineHeight、透明度 opacity、渐变角度等全部数值字段。

### 2.4 边缘场景

1. 数值边界 clamp：透明度 0-100、角度 0-360、尺寸 ≥0；到边界锁定。
2. 含单位/非数字（"24px"）→ 先解析数字再拖；解析失败不进入拖动。
3. 负值字段（定位偏移）从负值继续。
4. token 关联字段：拖动时解绑 token，切回显式数值。
5. 只读/禁用字段不响应拖动。
6. 整数字段输入过滤非数字。
7. 拖动中字段值实时更新显示。
8. 现有 ±1px 按钮不存在（键盘 ↑/↓ 已覆盖），不新增。

## 3. 悬停/选中元信息（替代网格吸附）

### 3.1 调整

- **移除**：8px 网格背景 + 拖拽吸附 + 吸附距离数字。
- **新增**（走查模式默认开启，无开关）：悬停/选中元素时显示——
  1. **四边延长线**：左/右/上/下四条延伸到视口边缘（对齐 Liaison gridlines）。
  2. **元信息气泡**：标签名（优先稳定 class，其次 tagName）+ 尺寸（宽 × 高 px）。
  3. **布局间距标注**：元素四边到最近参考（父容器内容边缘 / 相邻兄弟）的间距数字（对齐 Figma auto-layout）。
  4. **padding/margin 色块**：padding 内层色块 + margin 外层色块；hover 色块显示对应数值（padding 显示 padding、margin 显示 margin）。

### 3.2 触发

- 桌面端（主）：hover 显示、移开隐藏。
- 移动端（辅助）：选中显示、取消选中隐藏；色块**点击**显示数值。

### 3.3 视觉与层级

- z-index：页面之上、样式面板之下。
- 色块 / 延长线 / 间距标注共享一个 overlay 图层（复用 measure overlay 或新增元信息层）。
- 间距标注取**最近参考**；唯一子元素只显示到父容器边缘间距。
- 只显示当前 hover/选中元素的 padding/margin，不显示父级。

### 3.4 边缘场景

1. padding/margin 为 0：显示色块 + 数值 0。
2. margin 折叠：显示 computed 实际生效值。
3. 色块响应 hover（pointer-events）但不拦截页面点击（精细命中控制）。
4. 间距数字溢出（间距过小）→ 自动偏移。
5. hover 移动节流（复用 `_hoveredElement` 缓存）。
6. 元素宽/高为 0：延长线与间距标注的显示处理（正常显示，线重合时仍可读）。
7. 移动端：色块固定显示（选中态），点击色块显示数值；不处理 hover。

## 4. 渐变融入颜色选择器

### 4.1 弹层结构（对齐 Liaison）

```
┌ 颜色属性 ──────────── × ┐
│ [实色] [渐变]  ← segmented │
│ 渐变模式：                 │
│   ┌ 角度 −45° [==滑块==]° +45° ┐│
│   │ 调转 ⇄ │ 删除 −（≥2 时可用）││
│   └ 色标条：预览条 + 色标圆点 ┘│
│ SV 面板（色相/饱和度）         │
│ 滑块组：吸管 | 色相 | 透明度    │
│ 格式行：HEX/RGB/HSL | 数值 | 透明度% │
└──────────────────────────┘
```

### 4.2 多色标（对齐 Liaison）

- **点击色标条空白处** → 添加新色标（继承当前激活色标颜色，可改）。
- **点击色标圆点** → 激活，颜色区（SV/滑块/格式）作用于该色标。
- **拖动色标** → 调整 position（0-100%）。
- **删除色标** → 删除激活色标，**最少保留 2 个**；色标 >2 时删除按钮可用。
- **色标数量上限 5 个**。
- 每个色标独立透明度。

### 4.3 角度控件

- `−45°` 按钮 / range slider（0-360，步进 1）/ `+45°` 按钮；长按连续调。
- 显示当前角度值（如 `180°`）。
- **径向渐变**：无角度概念，角度控件隐藏/禁用。

### 4.4 支持范围

| 属性 | 渐变 | 说明 |
|---|---|---|
| 填充 | ✅ | background 渐变原生支持 |
| 文本色 | ✅ | `background-clip:text` + transparent（标准 CSS，非 hack） |
| 描边 | ❌ | CSS border 原生不支持，不做模拟 |
| 投影 | ❌ | box-shadow 原生不支持，不做近似 |

### 4.5 数据模型

```js
// 颜色字段统一
{
  type: 'solid' | 'gradient',
  hex: '#RRGGBB',          // solid 用
  opacity: 100,            // solid 用
  gradientType: 'linear' | 'radial',
  angle: 180,              // linear 用
  stops: [                 // gradient 用
    { hex: '#RRGGBB', opacity: 100, position: 0 },  // 2~5 个
    { hex: '#000000', opacity: 100, position: 100 }
  ]
}
```

- 现有双色渐变（gradientStart/gradientEnd）读入为 2 个 stops。
- 导出：`linear-gradient(angle, stop1, stop2, ...)` / `radial-gradient(circle, stop1, ...)`。
- 文本色渐变导出：`background-image` + `background-clip:text` + `color:transparent`。

### 4.6 边缘场景

1. token 关联字段：token 仅支持纯色，切渐变时解绑 token。
2. 色标 position 0-100% clamp。
3. 格式切换（HEX/RGB/HSL）作用于激活色标。
4. 渐变修改实时预览，面板关闭/确认时提交一次进撤销栈。
5. 多层填充每层渐变走同一弹层。
6. 向后兼容：旧双色数据读入、旧导出格式兼容。
7. 移动端：色标条 tap 加、拖动调位置可用。

## 5. 颜色选择器本体对齐 HSL

### 5.1 颜色模型 HSL

- 内部计算 HSV → **HSL**（`_hsl = { h, s, l }`）。
- 格式切换：HEX / RGB / **HSL**。
- SV 面板：S 轴不变，V(value) → L(lightness)；光标位置与背景换算调整。
- 色相滑块：不变（h 通道）。

### 5.2 三组独立输入

- **hex 模式**：单输入框（#RRGGBB）。
- **rgb 模式**：R / G / B 三个独立输入框（0-255）。
- **hsl 模式**：H（0-360）/ S（0-100%）/ L（0-100%）三个独立输入框。
- 任一通道修改实时生效并同步其他显示。

### 5.3 吸管位置

- 吸管（EyeDropper）从格式行**移到滑块组**，与色相滑块、透明度滑块并排。

### 5.4 其余结构（保留）

- header（标题 + 关闭 ×）
- SV 面板、色相滑块、透明度滑块 + 数字输入
- 实色/渐变切换（见功能 4）

### 5.5 边缘场景

1. token 值（var(--xxx)）打开时解析为实际 hex 显示（现有逻辑保留）。
2. HSL 与 HEX/RGB 互转精度（取整显示）。
3. 透明度独立于色模型，全程一致。
4. 输入非法值：回退/忽略，不破坏当前色。

## 8. 风险与兼容

- **HSL 模型改动**：影响颜色选择器全部换算与既有已存颜色数据的显示（需回归已存颜色）。
- **渐变数据迁移**：gradientStart/gradientEnd → stops 双色映射。
- **DOM 排序 vs 动态列表**：重放依赖渲染完成时机，需路由切换/渲染后 hook。
- **box-shadow/border 渐变不支持**：按用户决策不做兼容，颜色字段仅纯色。
