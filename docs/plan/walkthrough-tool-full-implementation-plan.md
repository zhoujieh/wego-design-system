## 一、项目概述

### 1.1 目标

在 wego-app 中内置一套完整的可视化走查工具，对齐 Liaison 插件的核心交互和 UI 体验，实现：

- 任意场景页面上点击元素，可视化编辑样式
- 元素批注与配置汇总
- 一键导出结构化 Prompt 交给 AI 修改源码
- 统一悬浮入口，整合现有失败注入功能
- 本地预览和在线预览通用

### 1.2 实现原则

- **交互对齐 Liaison**：元素选中、属性面板、配置列表、导出格式等核心交互严格对齐 Liaison
- **适配 wego-app**：面板形态、颜色体系、存储方式适配手机原型和设计系统
- **移除不相关功能**：作者社交链接（小红书/推特）、飞书反馈表单、浏览器右键菜单、扩展注入机制等
- **自有代码实现**：基于 Web Components + Shadow DOM 重新实现，不拷贝 Liaison 源码

### 1.3 移除的功能（Liaison 有但 wego-app 不需要）

| 功能 | 移除原因 |
|------|---------|
| 小红书作者主页链接 | 作者社交推广，与走查工具无关 |
| 推特/X 作者主页链接 | 同上 |
| 飞书问题反馈表单 | 我们有自己的反馈渠道，不需要外部表单 |
| 浏览器右键菜单（contextmenu） | 内嵌工具，通过悬浮入口操作，不需要右键菜单 |
| 扩展注入/退出机制（inject/eject/restore） | 页面内嵌加载，不需要动态注入 |
| chrome.storage 扩展存储 | 用 localStorage 替代 |
| React 调试信息 | 开发调试用，生产环境不需要 |
| 颜色模式/配色方案右键切换 | 简化为跟随系统，不需要独立切换 |

## 二、技术架构

### 2.1 技术选型

- **核心框架**：Web Components（Custom Elements + Shadow DOM）
- **样式隔离**：Shadow DOM，避免与页面 CSS 冲突
- **模块格式**：IIFE 封装，挂载到 `window.WegoApp.Walkthrough`
- **状态管理**：元素属性驱动（`data-*`），对齐 Liaison 的状态管理方式
- **数据持久化**：localStorage，按场景路由隔离

### 2.2 自定义元素清单（共 16 个，对齐 Liaison 并按手机端精简）

| 元素标签 | 职责 |

| `wego-wt-overlay` | 页面覆盖层（选中框、元素信息气泡、测量标记、网格线） |

### 2.4 与现有系统集成

1. **index.html**：引入 `walkthrough-tool.js` 和 `walkthrough-tool.css`
2. **app.js**：移除 `mountFaultSwitch` 代码（约 100 行），失败注入由走查工具托管
3. **API 兼容**：保持 `window.WegoApp.faultInjection.isEnabled()` / `setEnabled()` 接口不变，场景代码无需修改
4. **悬浮入口**：复用现有失败注入的位置（右下角 `bottom: 96px`）
5. **设计系统 Token**：面板样式使用 wego 设计系统 CSS 变量

### 2.5 手机端交互设计原则（核心约束）

wego-app 是 375px 手机原型，Liaison 的桌面端交互（右侧面板、顶部工具栏、8 个手柄、hover 预览）在手机屏上完全不适用。所有交互必须按以下原则重新设计：

| 原则 | 说明 |
|------|------|
| **底部抽屉式面板** | 所有功能面板（样式编辑、配置列表、批注）从底部滑出，占屏高 60-85%，可拖拽调整高度，下滑关闭。不使用左右侧面板 |
| **横向 Tab 切换分组** | 属性分组（定位/布局/字体等）用顶部横向滚动 Tab 切换，不用纵向折叠列表（手机端折叠点击区域小、操作繁琐） |
| **移除 8 个调整手柄** | 手机屏上 8 个手柄会重叠且手指精度不够，尺寸调整改用底部面板的数值输入 + 步进按钮 |
| **无 hover，直接触摸选中** | 触摸设备没有 hover 状态，走查模式下直接触摸元素即选中，不做悬停预览虚线 |
| **底部工具条** | 核心操作按钮放在底部工具条（悬浮按钮展开后），可横向滚动容纳更多按钮，不放在顶部（遮挡页面内容） |
| **元素信息气泡** | 选中元素的标签名+尺寸用气泡显示在元素上方（空间不够则下方），不固定在角落 |
| **最小点击区域 44px** | 所有按钮、手柄、Tab 的可点击区域不小于 44x44px，符合移动端交互规范 |
| **面板半透明+页面上移** | 底部抽屉打开时，页面内容可上移或面板半透明，确保能看到选中元素的实时变化 |
| **长按拖拽移动** | 元素移动用长按后拖拽（避免与滚动冲突），或通过面板的定位数值输入 |

## 三、功能模块详细设计

### 3.1 悬浮入口与底部工具条

#### 3.1.1 悬浮按钮（wego-wt-fab）

- **位置**：固定右下角，`right: 12px; bottom: 96px`（与现有失败注入一致）
- **形态**：圆形按钮（直径 48px），走查工具图标
- **状态指示**：任意功能开启时（走查模式/失败注入/有未导出变更）按钮右上角显示红色小圆点
- **点击行为**：展开/收起底部工具条

#### 3.1.2 底部工具条（展开后）

悬浮按钮点击后，从底部弹出一条横向工具条（高度 56px），位于悬浮按钮上方，包含核心操作按钮：

| 按钮 | 功能 | 说明 |
|------|------|------|
| **走查模式** | 切换走查模式（大按钮，最醒目，占宽度最大） | 开启后触摸元素即选中；关闭后恢复正常页面交互 |
| **配置列表** | 打开配置列表面板（底部抽屉） | 按钮上显示变更数量 badge |
| **测量** | 切换测量模式 | 开启后触摸两个元素显示间距 |
| **网格** | 切换网格辅助线显示 | 拖拽元素时自动吸附 |
| **更多** | 弹出更多菜单（向上弹出） | 导入、导出、重置、失败注入 |

**工具条特性**：
- 按钮可横向滚动（按钮多时左右滑动查看更多）
- 每个按钮最小点击区域 44x44px
- 走查模式按钮使用强调色填充，其他按钮使用次要样式
- 工具条左侧有拖拽手柄，可上下拖动调整工具条位置（可选）

#### 3.1.3 走查模式横幅

走查模式开启后，页面顶部出现一条 28px 高的横幅：
- 文字："走查模式 · 触摸元素选中"
- 右侧有"关闭"按钮
- 横幅半透明，不遮挡页面核心内容
- 走查模式关闭后横幅消失

#### 3.1.4 更多菜单

点击"更多"按钮后，在工具条上方向上弹出菜单：

- 导入配置（从 JSON 文件导入）
- 导出配置（导出为 JSON 文件）
- 重置修改（清空当前场景所有样式修改）
- ─── 分隔线 ───
- 失败注入（展开子菜单：加载失败、新增保存失败、删除失败，带开关状态）

操作结果用 toast 提示（复制成功/失败、导入成功/失败、导出成功/失败、重置成功）。

### 3.2 元素选中与高亮

#### 3.2.1 状态属性（手机端适配）

| 属性 | 视觉效果 | 触发时机 |
|------|---------|---------|
| `data-selected=true` | 实线边框（2px 品牌色）+ 元素信息气泡 | 触摸选中 |
| `data-selected-hide=true` | 隐藏选中态边框 | 文本编辑时或面板遮挡时 |
| `contenteditable=true` | 文本编辑模式，光标为强调色 | 双击/长按文本元素 |
| `data-measuring=true` | 十字准星 + 测量标记 | 测量模式 |
| `data-dragging=true` | 元素半透明 + 拖拽阴影 | 长按拖拽移动中 |

> 手机端无 hover，移除 `data-pseudo-select` 悬停预览态；移除 8 个调整手柄（手指精度不够且会重叠），尺寸调整通过底部面板数值输入。

#### 3.2.2 触摸选中

- 走查模式开启后，触摸页面元素即选中（阻止默认行为和事件冒泡）
- 选中元素显示**2px 实线边框**（品牌色）+ **元素信息气泡**
- 选中后自动从底部弹出样式编辑抽屉
- 触摸空白处取消选中（样式抽屉自动收起）
- 滑动页面时不触发选中（区分触摸和滑动）

#### 3.2.3 元素信息气泡

- 显示内容：标签名 + 尺寸（如 `button · 120×44`）
- 位置：优先显示在元素上方；元素靠近顶部时显示在下方
- 形态：小气泡，深色半透明背景，白色文字，圆角 6px
- 气泡不响应触摸事件（`pointer-events: none`），不影响操作
- 选中元素靠近屏幕边缘时，气泡自动调整水平位置避免超出屏幕

#### 3.2.4 尺寸调整（手机端方案）

手机端不使用 8 个拖拽手柄，改用以下方式调整尺寸：

1. **底部面板数值输入**：样式抽屉「定位」分组中有 width / height 数值输入框 + 步进按钮（±1px，长按连续加减）
2. **双指缩放**（可选，二期）：选中元素后双指捏合调整尺寸，类似地图缩放
3. **宽高比锁定**：数值输入框旁有锁定按钮，锁定后调整一个值另一个等比变化

#### 3.2.5 元素拖拽移动

- **长按触发**：选中元素后长按 500ms 进入拖拽模式（避免与页面滚动冲突）
- 拖拽中元素半透明（opacity: 0.8）+ 阴影加深
- 实时显示坐标偏移气泡（如 `+12, -8`）
- 松手后位置固定，变更记录到配置列表
- `a`、`img` 等元素禁用原生拖拽（`-webkit-user-drag: none`）
- 网格辅助线开启时，拖拽到其他元素边缘自动吸附

#### 3.2.6 文本内联编辑

- 双击或长按选中文本元素进入编辑模式（`contenteditable=true`）
- 光标颜色为强调色
- 弹出系统键盘，编辑完成后点击外部或按"完成"退出
- 文本修改纳入变更记录
- 编辑时隐藏选中边框（`data-selected-hide=true`），避免干扰

#### 3.2.7 CSS 选择器生成

为选中元素生成稳定 CSS 选择器，优先级：
1. 唯一 `id` → `#id`
2. 稳定 `data-*` 属性（`data-component-slug`、`data-dom-id` 等）
3. `tagname.class:nth-child(n)` 路径链，从最近的稳定祖先开始
4. 生成后验证唯一性（`querySelectorAll(selector).length === 1`）

### 3.3 样式编辑面板（wego-wt-style-panel）

#### 3.3.1 面板形态（底部抽屉）

- **触发**：选中元素后自动从底部滑出；也可通过工具条手动展开
- **默认高度**：占屏高 65%（约 530px / 812px）
- **可调整高度**：顶部拖拽条可上下拖动调整面板高度，范围 40%-85% 屏高
- **关闭方式**：下滑到底部关闭 / 点击关闭按钮 / 点击页面空白处 / 取消选中元素
- **半透明背景**：面板打开时，面板上方的页面区域添加半透明遮罩（可点击遮罩关闭面板）
- **页面联动**：面板打开时页面内容不自动上移，通过半透明遮罩确保能看到选中元素的实时变化；面板高度可手动调低以查看更多页面内容
- **动画**：滑入/滑出 300ms ease-out，对齐 Liaison 的动画节奏

#### 3.3.2 面板结构（从上到下）

**① 拖拽条 + 关闭区（高度 24px）**
- 顶部居中显示拖拽条（宽 36px，高 4px，圆角，灰色）
- 右侧关闭按钮（×，44x44px 点击区域）

**② 元素信息行（高度 48px）**
- 左侧：元素标签名 + 选择器摘要（如 `button.btn · 120×44`），超出横向滚动
- 右侧：**共享元素开关**（小开关按钮，开启后显示"共享 N"）
  - 共享元素开启后，修改同时应用到所有同类元素
  - 长按开关可查看命中的元素列表（可选）

**③ 属性分组 Tab 栏（高度 44px）**
- 横向滚动的 Tab 按钮，8 个分组：定位 | 布局 | 字体 | 外观 | 填充 | 描边 | 投影 | 圆角
- 当前选中 Tab 下划线强调 + 文字加粗
- Tab 可左右滑动查看（8 个在 375px 宽度下显示不全，需横向滚动）
- 每个 Tab 最小宽度 56px，点击区域 44x44px

**④ 属性内容区（弹性高度，可垂直滚动）**
- 当前选中分组的属性控件列表
- 每个属性一行：属性名（左）+ 控件（右）
- 控件类型：数值输入+步进、下拉选择、按钮组、颜色选择器、滑块、开关
- 数值输入框：点击弹出数字键盘，带 ±1px 步进按钮（长按连续加减）
- 颜色选择器：点击弹出颜色面板（底部弹层或全屏）
- 多层效果（填充/描边/投影）：每层一个卡片，可展开/折叠，可添加/删除层

**⑤ 底部操作栏（高度 48px）**
- 左侧：「重置此元素」按钮（文字按钮，危险色）
- 右侧：「完成」按钮（强调色填充按钮）
- 中间可显示当前变更计数（如"已修改 3 项"）

#### 3.3.3 属性分组（严格对齐 Liaison 顺序）

##### 分组 1：定位

| 属性 | 控件 | 说明 |
|------|------|------|
| position | 下拉选择 | static / relative / absolute / fixed / sticky |
| top / right / bottom / left | 数值输入 + 单位 | px / % |
| z-index | 数值输入 | 整数 |

##### 分组 2：自动布局

| 属性 | 控件 | 说明 |
|------|------|------|
| 布局方向 | 三档按钮组 | 纵向（flex column）/ 横向（flex row）/ 网格（grid） |
| 网格列数 | 快速预设 1/2/3/4 + 手动输入 | 仅网格模式；`repeat(N, 1fr)`，九宫格用 3 |
| 网格列宽类型 | 分段按钮 | 仅网格模式；Stretch（等宽 1fr，默认）/ Fixed（固定 px）/ Auto（内容自适应） |

### 3.13 撤销与重做

- **撤销栈**：会话级（不持久化），记录每次样式修改的 { property, oldValue, newValue, selector }
- **重做栈**：撤销后移入重做栈，再次修改时清空重做栈
- **快捷键**：`Ctrl + Z` 撤销，`Ctrl + Shift + Z` 重做（桌面端预览）
- **手机端入口**：样式抽屉底部操作栏的「撤销」按钮（可选，空间允许时显示）
- **撤销范围**：仅样式修改；批注添加/删除不支持撤销（避免误删后无法恢复，批注删除用左滑+确认）
- **共享元素修改**：撤销时同时恢复所有共享元素的原值

### 3.14 面板层级与互斥关系

手机屏空间有限，需明确各面板的层级和互斥关系：

| 面板 | z-index | 互斥关系 |
|------|---------|---------|
| 走查模式横幅 | 9000 | 常驻（走查模式开启时），不与其他面板互斥 |
| 悬浮按钮 | 9500 | 常驻，始终可点击 |
| 底部工具条 | 9400 | 悬浮按钮展开时显示，样式抽屉/配置抽屉打开时自动收起 |
| 样式编辑抽屉 | 9600 | 与配置抽屉互斥（打开一个时另一个自动关闭） |
| 配置列表抽屉 | 9600 | 与样式抽屉互斥 |
| 颜色选择器弹层 | 9700 | 在样式抽屉之上弹出，不关闭样式抽屉 |
| 更多菜单 | 9700 | 在工具条之上弹出，点击外部关闭 |

### 3.15 触摸与滑动区分

走查模式下需要区分「触摸选中元素」和「滑动页面」，避免滑动时误选中：

- **触摸开始（touchstart）**：记录起始坐标 (x1, y1) 和时间戳
- **触摸移动（touchmove）**：如果移动距离 > 10px，标记为「滑动」，不触发选中
- **触摸结束（touchend）**：
  - 如果移动距离 ≤ 10px 且触摸时长 < 500ms → 判定为「点击」，执行选中
  - 如果移动距离 > 10px → 判定为「滑动」，不执行选中，允许页面正常滚动
  - 如果触摸时长 ≥ 500ms 且移动距离 ≤ 10px → 判定为「长按」，触发元素拖拽（见 3.2.5）
- **走查模式下的页面滚动**：滑动时正常允许页面滚动，不拦截 touchmove 的默认行为
- **选中元素后的滑动**：已选中元素时，滑动页面不取消选中（用户可能需要滚动查看元素在不同位置的效果）

## 六、风险与应对

| 风险 | 影响 | 概率 | 应对措施 |
|------|------|------|---------|
| **CSS 选择器不稳定** | 动态列表元素导出后选择器失效 | 高 | 优先使用 `data-*` 属性；动态元素标注提示；二期研究文本+相对位置定位 |
| **触摸与滑动误触** | 走查模式下滑动页面时误选中元素 | 中 | 10px 移动距离阈值 + 500ms 长按阈值区分；滑动时不触发选中 |
| **抽屉层级互斥复杂** | 样式抽屉、配置抽屉、颜色弹层、更多菜单层级混乱 | 中 | 明确定义 z-index 层级和互斥关系（见 3.14）；颜色选择器作为子弹层不关闭父抽屉 |
| **手机视口面板空间有限** | 375px 宽度下面板拥挤，属性控件显示不全 | 中 | 底部抽屉式，属性分组用横向 Tab 切换，关键属性优先，数值输入紧凑布局 |
| **样式修改与页面交互冲突** | 走查模式下无法正常操作页面 | 中 | 明确的模式开关 + 视觉横幅，关闭后立即恢复 |
| **Shadow DOM 与页面事件冲突** | 工具 UI 拦截了页面事件 | 中 | 工具 UI 放在 Shadow DOM 内，事件冒泡隔离；走查模式下才拦截页面点击 |
| **多层填充/描边/投影复杂度** | 实现工作量大，容易出 bug | 中 | 先实现单层，多层作为同一组件的循环渲染；渐变编辑器独立组件 |
| **EyeDropper API 兼容性** | 屏幕取色在部分浏览器不可用 | 低 | 功能检测，不支持时隐藏「屏幕取色」按钮 |
| **localStorage 容量** | 大量变更数据超出 5MB | 低 | 按场景隔离，单场景数据量有限；提供重置功能 |
| **失败注入迁移兼容性** | 破坏场景中已有调用 | 低 | API 完全兼容；全面回归测试 |
| **高亮层性能** | 复杂页面滚动时卡顿 | 低 | rAF 节流；只在走查模式开启时渲染；事件委托 |
| **长按拖拽与页面滚动冲突** | 长按后拖拽可能触发页面滚动 | 低 | 长按触发后调用 preventDefault 阻止滚动；拖拽中设置 touch-action: none |

## 附录：关键决策记录

| 决策 | 选择 | 原因 |
|------|------|------|
| 实现方式 | Web Components + Shadow DOM 重新实现 | 对齐 Liaison 架构；样式隔离；不拷贝源码 |
| 功能范围 | 对齐 Liaison 全功能，移除不相关项 | 用户要求完整实现；移除社交链接/反馈表单/右键菜单等 |
| 面板形态 | 底部抽屉式（所有面板） | 375px 手机屏，右侧面板会占满全屏；底部抽屉符合移动端交互习惯 |
| 属性分组切换 | 横向滚动 Tab | 手机端纵向折叠点击区域小、操作繁琐；横向 Tab 一目了然 |
| 尺寸调整 | 数值输入+步进，不用 8 手柄 | 手机屏 8 手柄会重叠，手指精度不够；数值输入更精准 |
| 元素选中 | 触摸即选中，无 hover 预览 | 触摸设备无 hover 状态；直接选中减少操作步骤 |
| 元素移动 | 长按触发拖拽 | 避免与页面滚动冲突；长按 500ms 是移动端标准交互 |
| 颜色体系 | wego 设计系统 Token | 不使用 Liaison 霓虹色系；保持设计一致性 |
| 代码归属 | `wego-design/runtime/` 权威源 → `wego-app/lib/` | 设计系统运行时能力；由 wego-uxsystem-iterate 维护 |
| 持久化 | localStorage，按场景路由隔离 | 实现简单；与现有失败注入存储方式一致 |
| 快捷键 | 核心 8 个，不全量实现 15 组 | 手机端触摸操作为主；桌面端预览时辅助 |
| 失败注入 | 迁移到走查工具更多菜单，API 完全兼容 | 统一入口；不破坏现有场景代码 |
| 批注操作 | 左滑显示编辑/删除 | 移动端标准列表交互模式 |
| Toast 提示 | 统一 wego-wt-toast 组件，不使用 alert | 移动端体验标准，不打断操作流程 |
| 撤销重做 | 仅样式修改支持，批注不支持（避免误删） | 控制复杂度，批注删除用左滑+确认 |
| 面板层级 | 明确定义 z-index 和互斥关系 | 手机屏空间有限，避免多面板重叠混乱 |
| 触摸滑动区分 | 10px 移动阈值 + 500ms 长按阈值 | 走查模式下避免滑动页面时误选中元素 |
