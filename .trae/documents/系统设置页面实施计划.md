# 系统设置页面实施计划

## 一、摘要

在 `wego-app` 静态 App 中新增"系统设置"页面，作为"我的"Tab → "设置"入口下的二级页面。页面按截图还原入口列表结构（4 组共 9 个入口项 + 退出登录按钮 + 客服教我链接），点击每个入口仅给出"尚未接入"toast 提示，不实现下钻交互。

- **入口路径**：我的 → 设置 → 系统设置
- **route_id**：`my-system-settings`
- **场景目录**：`wego-app/scenes/系统设置/`
- **页面范式**：`generic-mobile-task-page`（fallback，因为现有的 `biz-rule-config` pagePattern 是编辑型 full-screen-modal，而本页是列表入口型）
- **打开方式**：push（场景级二级页，coversTabBar=true）

- `interaction_mode`: `select`

### 4.2 design_consumption_plan.json（设计消费）

**文件**：`wego-app/scenes/系统设置/_spec/design_consumption_plan.json`

- `surface_designs`:

  2. **system-setting-list**：

- `routeId`: `my-system-settings`
- `title`: `系统设置`
- `presentation`: `{ type: 'push', transition: 'slide-left', coversTabBar: true }`
- `template`: 空字符串（init 中动态渲染）
- `init(ctx)`:

## 五、假设与决策

1. **导航标题**：截图是 PC 端管理后台样式（顶部"代理&工具 / 我的"面包屑），但我们做的是移动端 App。按微信生态设置页惯例，导航标题使用"设置"。
2. **红点样式**："产品与笔记"右侧红点用 `.badge` 组件的 dot 形态表达。但需检查 badge 组件是否支持纯红点形态——如果不支持，用业务作用域小圆点实现。
3. **"去设置"文本**：第一行右侧"去设置"文字 + 箭头，使用 cell 的 `trailingSlot=custom-link` 模式，文本颜色为 secondary/link 色。
4. **退出登录按钮**：截图中是白底黑字圆角按钮，对应 `button` 组件的 `medium` 强调级，但 medium 是灰底？需要确认——medium 默认是灰底，danger 是灰底红字。退出登录用 `danger` 强调更合适（灰底红字），但截图是白底黑字。按截图实现：白底黑字 → 用 `weak` 强调级或自定义容器背景。
5. **点击行为**：用户明确说"不用做每个入口点击后的交互"，所以全部入口点击都给 toast "该功能尚未接入原型"。
6. **不做持久化**：页面纯展示入口，不涉及状态保存，不需要 localStorage。
