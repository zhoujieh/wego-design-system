#### 10.2 修订"顶部状态栏（phone-status）"章节（第 62-68 行）

**原文**：
```

- 背景透明，由下方导航栏/页面背景透出颜色
- 高度由 `--safe-area-top` Token 控制（桌面浏览器 env() 返回 0px，真机返回设备实际值；phone-frame 内 .phone-screen 提供 44px 模拟值）
- 导航栏自身加 `padding-top: var(--safe-area-top)`，让内容从安全区下方开始
- 导航栏背景透明，与状态栏一起透出页面背景色，视觉上无缝衔接
```

**改为**：
```
- `position: absolute; top: 0` 悬浮在屏幕最顶部，不占布局空间
- 背景透明，由下方导航栏/页面背景透出颜色
- 高度由 `--safe-area-top` Token 控制（桌面浏览器 env() 返回 0px，真机返回设备实际值；`.phone-screen` 内提供 44px 模拟值，移动端 @media 重置为 0）
- navbar 通过 sticky `top: var(--safe-area-top, 0px)` 自动避让顶部安全区（components.css 已统一配置，宿主无需额外处理）

- 任务产物模板（page-shell.html）和宿主模板（host-shell.html）的 `.phone-status` 同样遵循此 absolute 悬浮方案；`page.css` / `host-shell.css` 在 `.phone-screen` 内定义 Token 模拟值，移动端 @media 重置为 0 实现联动隐藏
```

#### 10.4 新增"底部固定元素 safe-area 让位"小节

在"底部 Home 指示器（phone-indicator）"章节之后、"安全区 Token"章节之前插入：

```markdown
### 底部固定元素 safe-area 让位

页面底部固定元素（bottom-nav、固定操作栏、固定按钮栏等）必须预留底部安全高度间距，规则：

- 固定元素底部 padding 使用 `padding-bottom: var(--safe-area-bottom, env(safe-area-inset-bottom, 0px))`（Token 优先、env 兜底）
- 已注册组件（如 bottom-nav）的 safe-area padding 由 `components.css` 统一提供，宿主和任务级 `page.css` 不重复覆盖
- 任务级自创固定操作栏（如底部保存按钮栏、底部结算栏）必须在 `page.css` 业务样式中显式声明 `padding-bottom: var(--safe-area-bottom, env(safe-area-inset-bottom, 0px))`
- 移动端 @media 通过在 `.phone-screen` 重置 `--safe-area-bottom: 0` 联动归零所有依赖样式，不逐个重置固定元素 padding
```

#### 10.5 修订"安全区 Token"章节（第 95-100 行）


**改为**：
```css

  --safe-area-bottom: 0;
}
```

并补一句说明："`env(safe-area-inset-*)` 由真机 WebView 返回实际值；桌面外壳通过 `.phone-screen` 内显式定义 Token 模拟值代替 env()，移动端同链接通过 @media 重置 Token 为 0 实现联动隐藏。"
