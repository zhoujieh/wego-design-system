## 关键路径

1. **浏览好友列表**：进入好友 tab → 默认字母排序展示列表 → 右侧悬浮索引定位
2. **切换排序**：点击导航栏右侧排序入口 → 字母 / 分组排序切换 → 列表重新分组
3. **搜索好友**：搜索框输入关键词 → 实时过滤匹配昵称 → 清空回到列表
4. **添加好友**：点击搜索框右侧加号 → 全屏表单 → 填写提交 → 成功 toast + 列表新增
