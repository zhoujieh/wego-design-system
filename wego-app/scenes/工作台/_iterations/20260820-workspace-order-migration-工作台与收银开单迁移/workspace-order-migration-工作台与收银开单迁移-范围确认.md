# 工作台与收银开单迁移范围确认

## 目标

把现有工作台与收银开单 demo 的当前效果迁移到团队设计系统仓库，供团队后续继续完善。

## 本次迁移

- 工作台主界面及销售开单入口。
- 收银开单主界面、成功页和现有完整交互。
- 来源仓库当前尚未提交的开单最新效果。
- 手机、平板横屏与桌面宽屏适配。
- 场景专属图片、图标，以及团队仓库新宿主和新资源路径适配。

## 不在本次范围

- 不覆盖团队仓库宿主和公共设计系统资源。
- 不搬运旧版 `_spec/archive` 历史文件。
- 不实现后续讨论中的实名认证新需求。
- 未经用户验收不合并 `main`。

## 入口与关键路径

工作台 Tab → 销售开单 → 收银开单 → 选择客户与发货方式 → 添加商品 → 结算 → 开单成功 → 返回工作台。
