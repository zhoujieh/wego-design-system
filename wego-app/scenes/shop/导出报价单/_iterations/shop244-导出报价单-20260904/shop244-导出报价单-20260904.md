## 目标（goal）

让店主把店铺商品快速生成多语言报价单并发给海外买家：从「我的」内容管理批量区进入报价导出，完成选品、报价单预览编辑（改价/多语言翻译/标题规格编辑）、报价记录管理与真实文件（Excel/PDF/图片）生成分享的完整闭环，全程移动端可交互。

***

## 纳入范围（included）

- 入口与分流：「我的」tab 内容管理（产品类型）「批量」链接拉起 actionsheet（五项：批量分享/批量编辑/批量导出/批量上下架/批量删除·云空间清理）；「批量导出」进入本报价流程；其余四项维持占位提示。

- 报价方式：选品页顶部支持「按产品报价 / 按图报价」切换（当前模式常显 + 展开菜单切换）；「报价记录」入口在顶部右侧，首次带引导气泡「你的报价单都在这」（仅出现一次）。

- 商品搜索与视图：搜索框占位「商品名、货号、搜索码」，支持清除；按产品模式下支持列表/宫格视图切换；筛选按钮激活高亮并带徽标。

- 筛选面板（functional）：右侧滑入近全高面板；内容三卡上下堆叠一体滚动（添加时间 → 分类 → 来源），各卡标题行滚动时依次吸附顶部（吸顶需避让电池栏与安全高度）；底部重置/确定（draft 暂存，关闭放弃）。

  - 添加时间卡：开始/结束日期点选调用系统日历（原生日期控件），快捷项 今天/昨天/本月，开始不得晚于结束（联动约束）。

  - 分类卡：按商品系列分组标签网格，默认显示 3 行，超出出现「查看更多」→ 进入二级面板（返回+标题+页面搜索框+全部选项+清除/确定，还原 Figma 形态）；选中单选。

  - 来源卡：位于最后一张卡；来源为商品来源店铺，卡片内上滑滚动到底自动加载下一批（分页懒加载 + 到底提示）；标题行提供小尺寸搜索组件（点击放大展开动画后过滤本卡选项）。

  - 选中规则默认单选（点选高亮、再点取消、不选=全部），业务交互以参考应用为准；卡标题行已选时显示绿色已选值 + 清除叉。

  - 筛选生效后：选品列表顶部显示已筛选条件条（可逐项删除）；列表无匹配显示「暂无相关结果」空态（隐藏搜索框）。

- 选品交互：按产品模式商品卡左侧勾选（cell 前）；按图模式按商品分组（组头全选 + 摘要 + 已选 x/y），组体图片宫格逐图勾选，报价以「图」为单位（同商品多图可各成一行）；底部批量栏：全选 + 已选计数下拉 + 「查看已选」sheet（可逐项移除）+ 下一步（无选择禁用）；分页滚动加载。

- 预览编辑页：顶部返回 +「报价单预览」；「继续添加产品」入口在页面内、表格上方（点击回选品追加，底栏按钮变「确定」只追加新选项）。

  - 表格信息区：目录名 + 语言切换器（16 种：中/英/日/韩/西/法/德/意/葡/俄/阿(rtl)/印地/印尼/越南/泰/土，选中勾）+ 标题输入框（默认「报价单 日期 时间」）+ 日期 + 合计（￥/$ 双币）。

  - 报价表格（组件化）：列序 图 | 价格 | 规格 | 货号 | 商品名 | 操作；列头行竖向滚动吸顶（仅列头，表头信息区随内容滚动）；价格/规格/货号/商品名均为常驻输入框；价格主币 ￥ 下方实时美元副显；支持区间价（￥min \~ max 双输入）；多行输入（规格）可展开更高且不撑开表格容器；删除行直接移除（无二次确认、无撤销，参考逻辑）；行删空显示空态。

  - 价格列头「批量」→ 批量改价 sheet：统一价格/统一加价/统一减价/尾数处理 4 模式；加价/减价支持按比例/按金额切换；尾数处理（不处理/去小数/个位9/十位99）；「恢复改价前」；取消/确定。

- 多语言翻译：切换语言触发「正在翻译中 X/Y」状态条 + 取消；真实调用 Google translate gtx 免费接口（浏览器直连 translate.googleapis.com, client=gtx，无密钥）；带可达性探测（先试翻「测试」，不通则跳过翻译显示原文，不阻塞主流程）；内存缓存；任何网络失败不出现 VPN/网络类提示，静默降级。

- 分享导出：预览底部 Excel/PDF 分段切换 + 分享主按钮；分享流程格式三选（PDF/Excel/图片）；真实生成文件（Excel/PDF/图片均在浏览器端生成）→ 进度页（spinner + 「正在生成X」+ 进度条百分比）→ 完成页（「已生成X报价单」+ 分享/完成/继续编辑）；失败态「生成失败」+ 重新分享/继续编辑；分享落地原生分享优先（navigator.share，支持时弹系统面板），不支持降级触发文件下载。

- 报价记录：标题搜索；卡片（前 3 行缩略图 + 标题 +「N 项 · ￥总价」+ 更新时间）；删除模式（勾选 + 批量删除 + 确认弹窗 + 左上「取消」）；空状态区分「暂无报价记录 / 暂无相关结果」（均隐藏搜索框）；记录持久化 localStorage，可再次打开进入预览继续编辑；退出预览有改动时弹「是否保存当前修改？」（保存进记录/不保存）。

- 原型商品数据增强：为商品补充 item\_no（数字风格货号）、search\_code（搜索码）、source（来源店铺）、category（按商品系列细分，替代现有全 'clothing'）及 specification 文本（由现有结构化规格 尺码/版型 拼接生成）。分类归属（5 系列）：西装外套=玫红/藏蓝/金扣/米杏亚麻感短袖西装；衬衫=蓝色格纹/粉色休闲衬衫；上衣=荷叶边方领上衣/运动感宽松上衣/基础针织上衣/字母卫衣；短外套=红色撞色短外套；套装=卡其工装组/千鸟格针织套/涂鸦牛仔套/格纹半裙套。来源归属（6 店）：云朵服饰商行=方领上衣/基础针织上衣；青禾女装档口=玫红/藏蓝/米杏西装；微光面料商行=格纹/粉色衬衫/撞色短外套；南风衣局服饰店=金扣西装/运动上衣/字母卫衣；漫川生活集合店=工装组/涂鸦牛仔套；拾光买手店=千鸟格套/格纹半裙套。

- 空状态能力：现有空状态组件不满足时允许扩展。

## 关键路径（critical\_paths）

- \[P1] 我的批量导出 → 选品页（按产品/按图报价、搜索、筛选、勾选）→ 下一步 → 预览编辑（标题/语言翻译/价格区间/批量改价）→ 分享 → 选格式 → 生成进度 → 完成页（下载/系统分享）→ 完成返回。

- \[P2] 预览编辑退出（有改动）→ 弹「是否保存当前修改？」→ 保存 → 报价记录列表出现该记录 → 点开记录可继续编辑 → 再分享。

- \[P3] 报价记录管理：记录页搜索标题 → 无结果「暂无相关结果」；进入删除模式勾选 → 批量删除确认 → 列表更新；无任何记录时「暂无报价记录」。

- \[P4] 选品追加：预览页「继续添加产品」→ 回选品（保留已选行）→ 追加勾选 → 底栏「确定」→ 只追加新选项回预览。

- \[P5] 筛选：筛选按钮 → 面板 draft 修改（时间/分类单选/来源懒加载）→ 确定 → 列表按条件过滤 + 条件条 + 徽标计数 → 逐项删除条件回退。

## 原型边界（prototype\_boundaries）

### quote-create

- mode: functional

- visible\_result: 从批量 actionsheet 进入选品页，可完成搜索、筛选、按产品/按图勾选、底部查看已选、下一步进入预览编辑页。

### quote-edit

- mode: functional

- visible\_result: 预览编辑页表格常驻输入可改价格（区间价/美元副显）、规格、货号、品名、标题；删除行、批量改价（4 模式/比例金额/尾数/恢复）实时更新合计（双币）；「继续添加产品」追加生效。

### quote-translate

- mode: functional

- visible\_result: 切换语言后出现「正在翻译中 X/Y」进度条与取消；成功显示对应语言文本，失败/不可达显示中文原文且不阻塞；网络异常无 VPN/网络提示。

### quote-filter

- mode: functional

- visible\_result: 筛选面板三段卡（标题吸顶、系统日期、分类查看更多二级面板、来源懒加载），draft 确定后列表过滤、条件条与徽标更新，可逐项删除条件。

### quote-share-generate

- mode: functional

- visible\_result: 选择格式后真实生成 Excel/PDF/图片文件并触发系统分享或下载；进度百分比、失败态重试、完成页操作齐备。

### quote-records

- mode: functional

- visible\_result: 保存/打开的报价记录进入 localStorage 列表，可搜索、删除（批量+确认）、再次打开编辑，空态区分。

## 状态（states）

- 默认主态（选品）：进入选品页 → 展示商品列表（按产品/按图两模式）+ 顶部搜索卡与筛选/视图控件 + 底部批量栏；筛选未开、未勾选时下一步禁用。

- 加载态（选品分页/来源懒加载）：列表或来源卡滚动到底 → 加载指示，加载完显示新一批；来源卡数据到底显示到底提示。

- 失败态（翻译）：语言切换且 gtx 不可达 → 翻译条转为原文展示，不弹网络/VPN 提示。

- 失败态（生成）：文件生成异常 → 进度页转「生成失败」+ 错误说明 + 重新分享/继续编辑。

- 空状态（选品）：搜索/筛选无匹配 → 「暂无相关结果」，隐藏搜索框。

- 空状态（记录）：无任何记录 → 「暂无报价记录」；搜索无匹配 → 「暂无相关结果」；均隐藏搜索框。

- 空状态（预览表格）：报价行全部删除 → 表格空态提示，可继续添加。

- 追加模式：预览点「继续添加产品」进入选品 → 底栏按钮为「确定」，仅提交新勾选项。

- 删除模式（记录）：记录页进入删除模式 → 卡片出现勾选 + 批量删除条 + 确认弹窗；左上「取消」退出。

- 引导态：首次进入选品（报价记录入口）→ 引导气泡「你的报价单都在这」，点击后不再出现。

- 翻译进行中：切换语言 → 状态条「正在翻译中 X/Y」+ 取消，期间可继续编辑。

## 数据契约（data\_contract）

### 商品（原型库增强）

- 字段：product\_id(现有)；item\_no：字符串，数字风格货号（新增强）；search\_code：字符串（新增强）；title/name；category：字符串，按商品系列细分（新增强，原恒为 'clothing'）；source：字符串来源店铺（新增强）；price：number，CNY；currency='CNY'；unit='件'；specs{sizes\[],fit}（现有结构化规格）；specification：由 sizes+fit 拼接的文本规格（报价规格默认值，可编辑）；image\_list/images\[]；image 主图。

- 产生入口：原型内置数据源（prototype-db 商品库素材；本迭代为其补字段，非用户产生数据）。

- 展示位置：选品列表/宫格、报价表格、记录缩略图、分享导出。

- 修改方式：本迭代不改商品库原始价格以外业务；报价行改动只发生在报价单行内。

### 报价行 QuoteRow

- 字段：id；product（商品快照引用）；image（行展示图）；itemNo；nameZh；specZh；price（当前有效价）；priceEdited（是否改过）；translations{}（目标语言缓存，语言 code→文本）；区间价支持 min/max 表达。

- 产生入口：选品页「下一步/确定」将勾选项生成报价行（按产品一行；按图一张图一行）。

- 展示位置：报价表格行。

- 修改方式：预览表格常驻输入（价格/规格/货号/品名）、删除行、批量改价、行新增（继续添加）。

### 报价记录 QuoteRecord

- 字段：id；title；createdAt/updatedAt；language；total；rowCount；rows\[]（报价行数组快照）。

- 产生入口：预览退出弹窗「保存」或分享前置保存（写入 localStorage，key 按 wego 命名约定：wego.quote.records）。

- 展示位置：报价记录页卡片。

- 修改方式：记录页再次打开编辑后更新；删除（单条删除按钮/批量勾选删除+确认）。

### 筛选条件（draft）

- 字段：dateRange{start,end}；source；category；每项可为空（=全部）；draft 与已应用 filters 分离。

- 产生入口：筛选面板内操作（草稿），点「确定」应用。

- 展示位置：选品列表过滤结果、顶部条件条、筛选按钮徽标。

- 修改方式：面板重置/逐项清除叉/条件条删除。

## 假设（assumptions）

- 美元按固定参考汇率折算（原型常量 1USD≈7.2CNY，可调），不做实时汇率请求。

- 来源店铺数量由 AI 按商品分布拟定（若干家店铺，每店多品），用于支撑来源懒加载演示；属于商品数据增强。

- 商品系列分类由 AI 按现有商品自然归属拟定（约 4–6 个系列），先经用户过目后定稿写入数据。

- 按图报价以「图」为报价行单位；同商品多图各成一行，图不同而品名/规格/货号相同。

- 16 种语言为固定清单；阿拉伯语启用 RTL。

- 分享落地：navigator.share 可用时弹系统分享面板（微信/WhatsApp 为示意渠道），不可用时真实下载文件；原型不做渠道内真实送达。

- 本迭代所需新交互能力（筛选卡族、滚动区块吸顶、基础报价表格、小尺寸搜索、多行展开输入、图片 80–160 尺寸规则等）由 wego-uxsystem-iterate 组件迭代沉淀进设计系统，沉淀不改变本 spec 描述的业务交互。

- 参考应用既有「VPN 提示」类网络错误提示在本迭代明确移除（网络失败一律静默降级）。

- 商家身份已内置，无登录。

- 删除行、删除报价行不做二次确认（参考应用逻辑）。
