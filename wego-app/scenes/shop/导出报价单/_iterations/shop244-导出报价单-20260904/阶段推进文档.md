## 4. 阶段B 已实现关键细节（选品页）

- **DOM**：`const quoteSelectTemplate` 顶层唯一 const 模板（registerScene 要求顶层、无 IIFE、无动态插值）。
- **组件 slug**（必须命中正式组件）：layout-page/navbar/popmenu/search/badge/button/bottom-action-bar/layout-grid/layout-flow/card/image/metric/checkbox/layout-scroll。
- **状态**：selectMode（product/image，localStorage `wego.quote.selectMode`）、view、query、page（PAGE_SIZE=6）、selected（按图模式 key=`product_id:idx`）。
- **交互**：模式切换 popmenu、搜索（名称/货号/搜索码）、列表/宫格视图、筛选（阶段C接入，当前徽标+条件条占位）、全选/清空（全选作用于全部筛选结果非当前页）、已选计数下拉、查看已选 sheet（可移除）、下一步（未选禁用，阶段D接入预览）、按图分组勾选（组头全选+已选 x/y）、滚动分页加载、首登引导气泡（localStorage `wego.quote.guideSeen`）。
- **空态**：搜索无匹配→隐藏搜索工具栏（toolbarEl.hidden）+空态卡「暂无相关结果」+「清空搜索」恢复；事件委托绑定在 scrollEl（含 listEl+emptyEl），否则空态卡按钮无法触发。
- **布局**：`.quote-count-menu` 底部弹层需进 `ctx.bindScrollLayout({ fixedRegions:[{selector:'.quote-count-menu',edge:'bottom',gap:8}] })`。
- **overlay**：查看已选 sheet 根需 `data-component-slug="actionsheet"`，关闭按钮需 `data-dom-id`（含 close 关键字）才能通过 overlay_close 校验。

## 5. 关键坑与经验（待收口登记到 `.tasks/experience-inbox.json`）

1. **spec.md 写入链路会转义 markdown 敏感字符**（`_`→`\_`、`[`→`\[`），标题里的 entry_points 等会被 iteration-record.mjs 解析报「必须是非空数组」。规避：用字节级命令（python）写 spec，写后检查标题无 `\` 再 submit-brief。
2. **Edit/Write 工具对含中文路径的文件不可用**（尝试 Edit prototype-db.js 失败）。改用 Python 字节级脚本或 Bash heredoc 写入。
3. **scene.js 正则含字面双引号会让契约 maskJavaScript 状态机错位**，吞掉后面代码（registerScene 检测 0 次）。正则内引号用 `"`/`'` 转义写法。
4. **CSS var() 禁 fallback**：`var(--spacer-48, 48px)` 非法，用已存在 token。
5. **契约校验器交互识别**：每个 data-dom-id 元素必须被 `querySelector('[data-dom-id="..."]')` 取出并直接 `addEventListener` 绑定（事件委托不被识别）；纯展示容器用 `data-role` 而非 data-dom-id。
6. **overlay 关闭校验**：overlay 关闭按钮需带 data-dom-id 且含 close/cancel 关键字；overlay 根需 data-component-slug="actionsheet"。
7. **横向溢出**：badge 徽标 absolute 定位必须有 `position:relative` 锚点（筛选按钮加 class），否则溢出视口。
8. **closeOverlay 与 navigate 竞争**：弹层内点按钮跳转需用 `openSheet` 的 `onDestroy` 回调暂存意图再 navigate（对齐 publish-fab.js 模式），否则 hash 被历史抖动吞掉。
9. **组件 display 覆盖 hidden**：设计系统组件可能设 `display:flex`，需在 scene.css 加 `.quote-page [hidden] { display: none; }` 保证 hidden 属性生效。
10. **模式切换需清空已选**：按产品/按图两种模式 selected key 语义不同，切换模式必须 `state.selected = {}`，否则计数错乱。
11. **「我的」场景既有运行时告警**：image-grid 组件缺 data-component-slug 为并行迭代既有问题，非本次改动引入，推进时勿误判。
