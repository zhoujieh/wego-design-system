## 元信息

- **迭代 ID**：shop243
- **主场景**：产品分享
- **关联场景**：动态、我的、发布产品
- **创建日期**：2026-08-27
- **状态**：draft

## 目标（goal）

构建通用化组件化分享面板，统一相册云分散的分享入口，扩展第三方平台分享（视频号/闲鱼/小红书/快手/抖音/微博/转转）、小程序链接分享、保存图片和系统分享能力。组件设计支持多内容类型扩展（产品/列表页/个人主页/单据/海报/订单等），本次迭代以产品分享为主实现，提升商家跨平台分发内容的效率和体验。

---

## 纳入范围（included）

- 分享面板组件化：统一标题栏、配置栏、分享渠道栏、其他操作栏、取消按钮五段式结构，所有分享场景共用一套 UI 与图标资源；组件按内容类型（contentType）驱动配置，支持产品/列表页/个人主页/单据/海报/订单等多类型扩展，本次以产品类型为主实现；组件设计需满足：配置驱动（新增类型仅扩展 config）、插槽机制（支持插入引导元素/活动入口/个性化内容）、事件回调（渠道选择/操作点击/配置变化/关闭）、样式可定制（CSS 变量+配置参数）、场景快速扩展（六类内容类型预留配置）
- 分享渠道栏适配规则：渠道按配置顺序动态分组，每组双行（每行 N 个、N=(面板宽−16)÷68 向下取整）、组宽=N×68、组间紧挨；item 固定 68px（含内部 4px 内距，item 间紧挨、相邻内距形成 8px 间距），渠道名最多显示两行；超出第一组容量（2N 个）的渠道进入下一组，横向滚动条式自由滑动（非分页吸附）；滚动指示器为滚动条式进度条（track+thumb 随滚动移动），仅有多组时显示，无第二组不显示
- 分享面板支持 7 个新平台：视频号、闲鱼、小红书、快手、抖音、微博、转转，走"下载到相册→跳转平台"路径
- 分享至 XX 弹窗：显示下载/复制结果、去发 XX 按钮、清理已下载图片入口
- 分享校验：仅文案拦截（toast）、未安装应用拦截（弹窗+去安装）
- 分享面板支持「更多」：拉起系统分享面板
- 分享面板支持小程序链接：微信好友、朋友圈、复制链接（微信收藏鸿蒙暂不支持）
- 分享面板支持「保存图片」：下载全部图片/视频到相册，带下载进度和异常处理
- 灰度升级弹窗：可关闭型（每天1次）+ 强制型（仅1次），动态页首次进入时弹出
- 动态页分享入口补全：动态页展示全商家产品（含自己发布的）；自己的产品显示「一键分享」按钮；别人的产品主按钮显示「一键转发」，点击进入转发编辑页（全部内容可修改，发布按钮改为「转发」），长按「一键转发」按钮拉起分享面板（分享的同时完成转发）；帮卖商品保持「邀请帮卖」主按钮 + 次级「转发」按钮逻辑不变；分享/转发完成后该产品标记为已转发并同步到我的相册，转为自己的产品，保留转发来源可查询，与原产品保持关联关系
- 所有有产品展示的页面均需提供分享入口，无入口的补充加入
- 动态页默认空状态，所有业务数据通过用户操作产生：发布产品后写入 localStorage，动态页和我的页读取展示，形成完整数据闭环；不再直接展示内置种子数据
- 发布产品图片选择支持两种模式：从线上图片选取（内置资源库，模拟已上传的线上数据）+ 从本地相册选取（真实调用系统相册，支持图片和视频多选）
- 本地数据统一管理层 `WegoApp.db`：封装用户业务数据的 CRUD 操作（动态、产品、好友、转发记录、分享设置等），所有场景通过统一接口读写 localStorage，默认空状态
- 产品分享面板场景管理重构：demo 状态展示场景（product-share-demo）从纯样式维度（标准/窄屏/简洁）重构为业务维度——按产品数据状态（S1 完整商品 / S2 纯文字 / S3 视频为主，共 3 态）组织入口卡片，点击各状态拉起对应数据状态的分享面板，展示该状态下的面板表现（渠道可用性/操作项）与点击渠道后的交互提示差异；**面板内容元素（标题栏、配置栏、分享渠道栏、其他操作栏、取消按钮）固定不变，除非用户明确要求**，变化的是点击渠道后的交互流程和提示；S2 视频商品并入 S1 完整商品（有图或图+视频的常规商品形态），不再单列；窄屏双组+指示器作为面板自身响应式能力保留，不再作为独立 demo 场景；简洁模式不再作为独立演示入口（遵循面板内容元素固定不变原则）

## 入口（entry_points）

**通用交互规则（所有场景一致）**：
- 分享面板均在当前页从底部弹出，用组件实现，不跳转新页面
- 点击分享渠道后，分享面板关闭，停留当前页面执行后续分享动作，页面滚动位置保持不变
- 保存图片停留当前页执行下载任务，显示下载进度，完成/失败弹对应提示
- 分享失败（网络异常/未安装应用等）停留当前页弹 toast/弹窗
- 小程序链接二级面板：点击渠道后直接执行分享不返回主面板；仅点击取消或遮罩时重新打开主面板

- 动态页：展示全商家产品（含自己发布的）；通过 `publisher_id === currentUser.user_id` 区分自己/别人的产品；自己的产品列表项主按钮显示「一键分享」，点击拉起分享面板；别人的产品列表项主按钮显示「一键转发」，**点击**进入转发编辑页（全部内容可修改，发布按钮改为「转发」，点击转发后产品存入我的相册），**长按「一键转发」按钮**拉起分享面板（分享的同时完成转发）；帮卖商品保持「邀请帮卖」主按钮 + 次级「转发」按钮逻辑不变，帮卖场景也有转发按钮；分享/转发完成后该产品标记为已转发并同步到我的相册，转为自己的产品，保留转发来源可查询，与原产品保持关联关系
- 动态详情页「一键分享」按钮：页面底部操作栏，始终可见，点击拉起分享面板；产品详情模态（点击产品卡进入）新增分享入口，按"有产品的地方就要能分享"原则加入
- 我的页商品「分享」按钮：列表项操作区，点击拉起分享面板
- 发布/编辑/转发页：当前无分享和快捷分享入口，本次需新增；导航栏右侧与「发布」按钮并列，发布第一优先级、分享第二优先级；「分享」按钮点击拉起完整分享面板；「快捷分享」按钮默认显示朋友圈，用户通过分享面板选择渠道后，快捷分享动态更新为最近使用的渠道，点击快捷分享直接执行该渠道分享（不拉起面板）；点击任意分享渠道开始分享时，先自动保存当前产品，再继续执行分享；发布/编辑/转发页交互一致，分享内容均为保存后的自己的产品
- 其他有产品展示的页面：均需提供分享入口，无入口的补充加入
- 灰度升级弹窗：动态页首次进入时弹出，覆盖在页面之上

## 关键路径（critical_paths）

- [P1] 动态页自己的产品 → 点击一键分享 → 当前页底部弹出分享面板 → 选择分享渠道 → 面板关闭，停留当前页（滚动位置不变）执行分享 → 完成分享 → toast「分享成功」
- [P1] 动态页别人的产品 → 点击「一键转发」按钮 → 进入转发编辑页（全部内容可修改，发布按钮改为「转发」）→ 点击「转发」→ 产品存入我的相册（与原产品保持关联，保留来源字段）→ toast「转发成功」
- [P1] 动态页别人的产品 → 长按「一键转发」按钮 → 当前页底部弹出分享面板（分享的同时完成转发）→ 选择分享渠道 → 面板关闭，停留当前页（滚动位置不变）执行分享 → 完成分享 → 产品标记已转发并同步到我的相册（与原产品保持关联，保留来源字段）→ toast「转发成功」
- [P1] 动态详情页 → 点击一键分享 → 当前页底部弹出分享面板 → 点击小红书 → 面板关闭，停留当前页（滚动位置不变）→ 正在分享加载 → 系统保存弹窗（允许）→ 分享至小红书弹窗 → 点击去发小红书 → 系统打开弹窗（打开）→ 跳转小红书首页 → 返回 App → toast「分享成功」
- [P1] 动态详情页 → 点击一键分享 → 当前页底部弹出分享面板 → 点击小程序链接 → 主面板关闭 → 新弹出「分享小程序链接」面板 → 点击微信好友 → 校验安装微信 → 跳转微信选择聊天 → 选好友 → 发送 → 微信对话框显示小程序链接卡片（非取消场景不重新打开主面板）
- [P1] 发布/编辑/转发页 → 点击导航栏「分享」按钮 → 先自动保存当前产品 → 当前页拉起分享面板 → 选择分享渠道 → 跳转渠道分享 → 返回相册 → 关闭当前页并按页面类型 toast：发布页「发布成功」、编辑页「保存成功」、转发页「转发成功」；快捷分享按钮更新为本次使用的渠道
- [P1] 发布/编辑/转发页 → 点击导航栏「快捷分享」按钮（默认朋友圈/或最近使用渠道）→ 先自动保存当前产品 → 直接执行该渠道分享（不拉起面板）→ 跳转渠道分享 → 返回相册 → 关闭当前页并按页面类型 toast：发布页「发布成功」、编辑页「保存成功」、转发页「转发成功」
- [P1] 动态详情页 → 点击一键分享 → 当前页底部弹出分享面板 → 点击保存图片 → 面板关闭，停留当前页（滚动位置不变）→ 居中加载进度浮层（白色进度环+百分比）→ 下载完成 → guide toast「下载成功，文字已复制」+「去微信分享」
- [P1] 动态详情页 → 点击一键分享 → 当前页底部弹出分享面板 → 点击更多 → 面板关闭，停留当前页（滚动位置不变）→ 正在分享 → 拉起系统分享面板 → 选择平台 → 跳转对应平台
- [P2] 分享面板 → 点击微博 → 仅文案场景 → toast「请选择图片/视频分享」（微博例外：仅文案仍可跳转发布页自动携带文案）
- [P2] 分享至 XX 弹窗 → 点击去发 XX → 未安装对应应用 → 弹窗「请先安装 XX」+ 取消/去安装
- [P2] 分享至朋友圈弹窗 → 点击清理已下载图片 → 系统确认弹窗 → 确认后删除本次下载内容
- [P2] 动态页首次进入 → 触发可关闭型灰度弹窗 → 点击近期不再提醒 → 关闭弹窗，当天不再弹出
- [P2] 动态页首次进入 → 触发强制型灰度弹窗 → 点击立即体验 → toast 提示跳转手机应用市场

## 原型边界（prototype_boundaries）

### share-panel-open

- mode: functional
- visible_result: 所有场景点击分享入口后，当前页从底部弹出通用分享面板，不跳转新页面；面板为配置驱动的组件化结构，核心设计如下：
  - **五段式固定结构**：标题栏、配置栏、分享渠道栏、其他操作栏、取消按钮，结构不可变，内容按 config 渲染
  - **配置驱动**：通过 SharePanelConfig 定义每个 contentType 的面板内容，新增内容类型（列表页/个人主页/单据/海报/订单）仅扩展 config，不改组件核心
  - **标题栏**：左侧内容标题（config.title，如「分享产品」「分享海报」）+ 右侧固定「展示方式」「分享设置」入口（config.showHeaderActions 控制显隐，点击 toast 提示已有功能）
  - **配置栏**：按 config.configItems 渲染选项（产品类型为小程序码/文案带链接多选 + 给客户打标），支持单选/多选/开关等控件类型；小程序码与文案带链接为两个独立配置项，可同时勾选（多选），每项独立生效；勾选「小程序码」时，分享或下载把第一张图变成带二维码的海报；勾选「文案带链接」时，分享时自动复制产品文案并追加链接（微信渠道追加小程序链接，其他渠道追加网址短链接，链接模拟）；点击给客户打标 toast 提示已有功能
  - **分享渠道栏**：按 config.channels 渲染渠道图标（共11个渠道，顺序：朋友圈、海报分享[防折叠]、微信好友、视频号、闲鱼、小红书、快手、抖音、微博、转转、更多）；布局为动态分组：每行 N 个（N=(面板宽−16)÷68 向下取整）、每组双行最多 2N 个、组宽=N×68、组间紧挨、横向滚动条式自由滑动；item 68px（含 4px 内距，item 间紧挨）、渠道名最多两行；滚动指示器为滚动条式进度条（仅有多组时显示，无第二组不显示）；所有渠道后续功能模拟流程，不下钻具体实现；渠道可用性按 contentType 配置
  - **其他操作栏**：按 config.actions 渲染操作项（产品类型为小程序链接/保存图片/打商品条码），支持图标+文字或纯文字样式；打商品条码点击模拟反馈，不下钻具体功能
  - **插槽机制**：支持 config.customSections 注入自定义内容块，可插入引导元素（如新功能引导气泡）、活动入口（限时活动 banner）、个性化提示等，位置可配置在配置栏上方/下方、渠道栏上方/下方
  - **事件回调**：onChannelSelect(channelKey)、onAction(actionKey)、onConfigChange(key, value)、onClose()，各场景通过回调执行业务逻辑
  - **样式可定制**：面板高度、圆角、背景色通过 CSS 变量控制；渠道图标大小、间距通过 config 配置；支持深色/浅色模式
  - 点击遮罩或取消按钮面板关闭；点击分享渠道/操作项后面板关闭，停留当前页面（滚动位置保持不变）执行后续动作；新增内容类型只需扩展 config，面板结构和交互不变

### share-panel-data-states

- mode: functional
- visible_result: 产品分享面板 demo 场景（product-share-demo）按产品数据状态组织入口卡片（共 3 态，纯链接业务不存在，S2 视频商品并入 S1），点击各卡片拉起对应数据状态的分享面板，面板内容元素固定不变，差异体现在各状态点击渠道后的交互流程与提示：

## 状态（states）

- 分享面板默认态：所有场景点击分享入口 → 当前页面板从底部滑入，不跳转新页面，展示完整五段式结构，渠道栏按屏宽适配行数和滚动指示器
- 分享加载态：点击分享渠道/小程序链接/更多 → 面板关闭，停留当前页（滚动位置保持不变），页面中央显示「正在分享」加载提示
- 分享成功态：完成跳转返回 App → toast「分享成功」（发布/编辑/转发页入口对应显示发布/保存/转发成功）
- 转发成功态：别人的产品点击「一键转发」进入编辑页，点击「转发」后产品存入我的相册；或长按「一键转发」按钮拉起分享面板，分享完成后产品标记已转发并同步到我的相册；转发后的产品 isOwn=true，保留 forwardFrom 来源字段，与原产品保持关联关系，在我的相册中与自己发布的产品无区别 → toast「转发成功」；动态页和我的页实时刷新，产品卡片显示「已转发」标识
- 分享成功态（自己的产品）：自己的产品完成分享后 → 动态页和我的页实时刷新，产品卡片显示「已分享」标识 → toast「分享成功」
- 分享失败态：
  - 网络异常（第三方平台分享/更多/小程序链接）→ toast「网络异常，分享失败」（不提供重试，用户需重新点击分享）
  - 未安装对应应用（点击去发 XX 时校验）→ 弹窗「请先安装 XX」+ 取消/去安装
  - 仅文案产品（点击第三方平台时校验，微博除外）→ toast「请选择图片/视频分享」
  - 未安装微信（小程序链接分享时校验）→ toast「请安装微信」
- 保存图片进度态：点击保存图片 → 居中弹出加载进度浮层（白色进度环 + 百分比 +「正在下载」文案，无文件名/序号/中断按钮）；按"图片优先、视频最后、多组按组排列"顺序依次下载，进度按已下载文件数/总文件数计算
- 保存图片完成态：全部素材下载完成 → 进度浮层关闭 → guide toast「下载成功，文字已复制」+「去微信分享」
- 保存图片上传中拦截态：产品正在上传时点击保存图片 → 不弹进度浮层 → toast「图片/视频正在上传，请稍后再试」
- 保存图片失败态：下载过程网络异常 → 进度停止 → 浮层关闭 → toast「网络异常，下载失败」
- 系统保存弹窗态：第三方平台分享下载完成后触发（首次或权限过期时），显示「允许"微购相册"应用保存图片和视频？」+ 禁止/允许；点击允许后获取30分钟自动保存权限，期间再次分享跳过此弹窗直接下载
- 分享下载中态：第三方平台分享时，面板关闭后显示「正在分享」加载提示，后台静默下载全部素材到相册，不显示显式进度条
- 快捷分享默认态：发布/编辑/转发页导航栏快捷分享按钮默认显示朋友圈图标，点击直接执行朋友圈分享（不拉起面板）
- 快捷分享更新态：用户通过分享面板选择某渠道完成分享后，快捷分享按钮图标和文案更新为该最近使用渠道，后续点击直接执行该渠道分享
- 发布页分享保存中态：发布/编辑/转发页点击分享或快捷分享时，先自动保存当前产品，保存成功后再继续执行分享流程
- 发布页分享返回态：跳转渠道分享后返回相册，分享完成等同于发布/编辑/转发完成，关闭当前页并按页面类型 toast：发布页「发布成功」、编辑页「保存成功」、转发页「转发成功」
- 灰度弹窗可关闭态：动态页首次进入触发 → 弹窗覆盖页面，含立即体验/近期不再提醒/叉号，每天首次弹出
- 灰度弹窗强制态：动态页首次进入触发 → 弹窗覆盖页面，仅立即体验按钮，首次弹出
- 空状态（仅文案产品，即 S2 纯文字）：产品无图片/视频时进入 → 「保存图片」按钮隐藏（需求范围，仅文案产品无保存按钮），点击朋友圈/海报分享提示「暂无图片」、视频号提示「暂不支持」；微信好友复制文案+链接、小程序链接正常复制；第三方平台（微博除外）→ toast「请选择图片/视频分享」拦截；微博允许仅文案分享，走正常流程跳转发布页自动携带文案
- 动态页空状态：首次进入或无任何发布内容时 → 展示空状态（插图+文案+去发布按钮）；发布产品后 → 数据写入 localStorage → 动态页刷新展示内容

**数据状态（场景管理维度，纯链接业务不存在，S2 视频商品并入 S1）**：
- S1 完整商品态：分享内容含图片（1-9 张）+ 标题，可含视频 → 面板完整五段式展示；朋友圈/海报生成图片/视频分享、微信好友图片/视频+文案、保存图片保存图片/视频到相册，均可正常执行
- S2 纯文字态：分享内容仅标题、无图无视频 → 「保存图片」按钮隐藏（仅文案产品无保存按钮），点击朋友圈/海报分享提示「暂无图片」、视频号提示「暂不支持」、微信好友复制文案+链接，小程序链接正常复制
- S3 视频为主态：分享内容含视频 + 标题、无图片 → 面板展示不变；朋友圈/微信好友/视频号以视频分享、保存按钮文案为「保存视频」；海报分享提示「暂无图片」

## 数据契约（data_contract）

### 分享内容（通用）

- 字段：id(string)、contentType(string, 内容类型：product/list/profile/receipt/poster/order 等，本次实现 product)、title(string, 内容标题/文案)、shopName(string, 店铺名)、images(array<string>, 图片URL列表)、videos(array<string>, 视频URL列表)、miniprogramPath(string, 小程序路径)、miniprogramShortLink(string, 小程序短链)、longLink(string, 长链接)、uploading(boolean, 是否正在上传)、isOwn(boolean, 是否自己的内容)、forwardFrom(string, 转发来源，转发内容有值)、config(object, 按 contentType 差异化的面板配置：标题栏文案、配置栏选项、可用渠道、其他操作项)
- 数据状态（dataState，string）：由 images/videos/title 组合推导，S1 完整商品（图+标题，可含视频）/ S2 纯文字（仅标题）/ S3 视频为主（视频+标题，无图）；纯链接业务不存在，S2 视频商品并入 S1；用于 demo 场景按业务维度组织入口与渠道交互差异判断
- 产生入口：各业务页面加载时读取当前分享内容数据（原型内置产品类型示例数据，预留其他类型扩展）；demo 场景各数据状态入口的分享内容来自对应状态的产品数据（含真实发布产生的与演示用示例数据，用于展示各状态下面板表现）
- 展示位置：分享面板标题栏/配置栏（按 contentType 渲染对应配置）、分享至 XX 弹窗、小程序链接内容、保存图片范围、内容卡片
- 修改方式：配置栏切换分享内容形态（如小程序码/文案带链接）；别人的产品一键转发并完成分享后，该产品标记为已转发、同步到我的相册、isOwn 变为 true，同时写入 forwardFrom 保留转发来源，可查询是转的谁的；新增 contentType 时扩展 config 配置，面板结构不变

### 分享面板组件配置（SharePanelConfig）

- 字段：contentType(string, 内容类型标识)、title(string, 面板标题，如「分享产品」)、showHeaderActions(boolean, 是否显示标题栏右侧展示方式/分享设置入口，默认 true)、configItems(array<ConfigItem>, 配置栏选项列表)、channels(array<string>, 可用渠道 key 列表，按顺序渲染)、channelGroups(object, 渠道分组配置，如 {1: ['moments','wechat'], 2: ['xiaohongshu','douyin']})、actions(array<ActionItem>, 其他操作栏项列表)、customSections(array<CustomSection>, 自定义插槽内容，支持引导元素/活动入口/个性化提示)、style(object, 样式覆盖，如 panelHeight、radius、bgColor)
- 产生入口：组件内置各 contentType 的默认配置，各场景调用时可传入覆盖配置
- 展示位置：分享面板整体结构渲染
- 修改方式：新增 contentType 时新增 config 配置；个性化需求通过 customSections 注入；样式通过 style 或 CSS 变量覆盖

### 配置栏选项（ConfigItem）

- 字段：key(string)、label(string)、type(string, radio/checkbox/switch/button)、options(array<{value,label}>, 单选/多选选项)、defaultValue(any)、onChange(callback, 值变化回调)
- 产生入口：SharePanelConfig.configItems
- 展示位置：分享面板配置栏
- 修改方式：按 contentType 配置，产品类型默认小程序码/文案带链接多选（checkbox，两项独立可同时勾选）+ 给客户打标按钮

### 其他操作项（ActionItem）

- 字段：key(string)、label(string)、icon(string, 图标 class)、style(string, icon-text/text)、onClick(callback, 点击回调)
- 产生入口：SharePanelConfig.actions
- 展示位置：分享面板其他操作栏
- 修改方式：按 contentType 配置，产品类型默认小程序链接/保存图片

### 自定义插槽（CustomSection）

- 字段：id(string)、position(string, config-top/config-bottom/channel-top/channel-bottom/action-top)、render(function|string, 渲染内容，支持 HTML 字符串或渲染函数)、dismissible(boolean, 是否可关闭)
- 产生入口：SharePanelConfig.customSections，各场景按需注入
- 展示位置：分享面板指定位置
- 修改方式：场景级配置，用于插入引导元素、活动 banner、新功能提示等个性化内容

### 分享渠道配置

- 字段：key(string)、name(string)、icon(string)、group(number, 1=第一组 2=第二组)、installed(boolean, 是否已安装)、supportTextOnly(boolean, 是否支持仅文案分享)
- 产生入口：原型内置固定渠道列表，共11个渠道（顺序：朋友圈、海报分享[防折叠]、微信好友、视频号、闲鱼、小红书、快手、抖音、微博、转转、更多）；所有渠道后续功能模拟流程，不下钻具体实现
- 展示位置：分享渠道栏，按配置顺序动态分组（每行 N 个、每组双行最多 2N 个、组宽=N×68），横向滚动条式滑动
- 修改方式：不可修改，固定配置

### 快捷分享记录（持久化）

- 字段：lastUsedChannel(string, 最近使用的分享渠道 key，默认 moments)
- 产生入口：用户通过分享面板选择某渠道完成分享后更新
- 存储位置：localStorage（key: wego.share.quick-channel），全局记忆，所有场景共享
- 展示位置：发布/编辑/转发页导航栏快捷分享按钮的图标和文案
- 修改方式：用户每次通过分享面板完成分享后更新为本次使用的渠道；快捷分享按钮点击直接使用该渠道执行分享，不更新记录

### 下载任务

- 字段：id(string)、progress(number, 0-100，按已下载文件数/总文件数计算)、status(string, pending/downloading/success/failed/cancelled)、totalCount(number, 待下载素材总数)、downloadedCount(number, 已下载数)、currentFileName(string, 当前下载文件名)、downloadOrder(array<string>, 按"图片优先、视频最后、多组按组排列"排序后的下载队列)、savePermissionGranted(boolean, 是否已获取30分钟自动保存至相册权限)
- 产生入口：点击保存图片时创建显式下载任务（带进度弹窗）；点击第三方平台分享时创建隐式下载任务（"正在分享"加载态，后台静默下载）
- 展示位置：保存图片加载进度浮层（显式任务，居中白色进度环+百分比）；分享至 XX 弹窗的下载完成标记（隐式任务）
- 修改方式：下载过程中 downloadedCount 递增、progress 按比例更新；全部完成后 status=success；网络异常后 status=failed；点击系统保存弹窗"允许"后 savePermissionGranted=true，30分钟内有效

### 转发产品记录（持久化）

- 字段：productId(string, 转发后新产品ID)、originalProductId(string, 原产品ID，关联关系)、forwardFromId(string, 来源店铺ID)、forwardFromName(string, 来源店铺名称)、forwardedAt(string, 转发时间)、productData(object, 转发时的产品快照，全部内容可修改)、isOwn(boolean, 固定 true)、relation(string, 与原产品的关联关系标识)
- 产生入口：别人的产品点击「一键转发」进入编辑页后点击「转发」，或长按「一键转发」按钮完成分享后
- 存储位置：localStorage（key: wego.product.forwarded，数组结构）
- 展示位置：我的页商品列表（读取时合并转发产品，实现同步到我的相册）；转发后的产品与自己发布的产品无区别，仅多一个来源字段值
- 修改方式：转发成功后写入；转发编辑页可修改全部内容；不可修改原产品，仅与原产品保持关联关系

### 灰度弹窗记录（持久化）

- 字段：type(string, dismissible=可关闭型 / forced=强制型)、lastShownDate(string, 最后弹出日期 YYYY-MM-DD，可关闭型用)、shown(boolean, 是否已弹出，强制型用)
- 产生入口：动态页首次进入时检查并弹出
- 存储位置：localStorage（key: wego.gray-popup.{type}）
- 展示位置：动态页覆盖层
- 修改方式：可关闭型每天首次进入弹出，弹出后更新 lastShownDate；强制型首次弹出后 shown=true，后续不再弹出

### 本地数据统一管理层（WegoApp.db）

- 定位：封装所有用户业务数据的 localStorage 读写，各场景不再直接操作 localStorage
- 命名规范：统一 `wego.{domain}.{entity}` 格式（如 wego.dynamic.published、wego.product.forwarded、wego.share.quick-channel）
- 接口：get(key)、set(key, value)、push(key, item)、remove(key, id)、find(key, predicate)、query(key, options)
- 管理范围：用户发布的动态、转发的产品、好友列表、分享设置（快捷渠道/保存权限/灰度弹窗）、订单偏好等所有用户产生的业务数据
- 内置资源（WEGO_PROTOTYPE_DB）：仅作为发布/添加时的可选素材（线上图片、商家账号、分类等），不直接作为业务数据展示
- 默认状态：所有用户业务数据默认空，通过真实交互流程产生后写入
