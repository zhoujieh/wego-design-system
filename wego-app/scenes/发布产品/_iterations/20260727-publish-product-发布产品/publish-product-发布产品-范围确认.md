# 发布产品｜范围确认

## 一、目标

让已登录的相册主身份从「我的」发布托盘进入独立发布页，在一个连续表单中完成产品图文与商品属性录入，提交后明确看到发布成功，并在「我的 → 产品」列表顶部看到新产品。

## 二、本次纳入

- 「我的」右下角发布托盘中的「发产品」升级为真实页面入口。
- 单页纵向发布表单：顶部返回、底部固定发布主操作。
- 图文信息：产品图片、产品文案。
- 商品属性：标签、货号、规格、颜色、售价、库存、库存对外可见。
- 图片、产品文案、售价的就地校验。
- 发布中、发布成功反馈，以及返回「我的 → 产品」后的新产品置顶。
- 使用仓库已有商品素材模拟选图，不执行真实上传。

## 三、本次不做

- 真实图片上传、系统权限、裁剪、压缩和云端传输。
- 草稿、定时发布、审核、失败重试和刷新后持久化。
- SKU 组合、分规格价格/库存、批发价。
- 分类、物流、售后、佣金、营销和交易设置。
- 批量/Excel 导入、平台搬家、扫码发布。
- 已发布产品的编辑、上下架、删除和批量管理。
- 自动生成动态或分享至微信。

## 四、入口

- `我的 tab → 发布 FAB → 发布托盘「发产品」→ 发布产品页`
- 发布页返回后恢复「我的」产品 tab 与列表视图上下文。

## 五、关键路径

1. 进入「我的」，展开发布托盘并选择「发产品」。
2. 选择图片、填写产品文案和商品属性。
3. 点击底部固定「发布」。
4. 必要信息缺失时就地提示并保留已填内容。
5. 校验通过后显示发布中与成功反馈。
6. 返回「我的 → 产品」，新产品显示在列表顶部。

## 六、原型边界

| flow_id | mode | visible_result |
| --- | --- | --- |
| `open-publish-product` | functional | 从「我的」发布托盘进入独立发布页，返回恢复列表上下文 |
| `fill-product-form` | functional | 可选择模拟图片并填写已收集到的产品字段 |
| `validate-product-form` | functional | 图片、产品文案或售价缺失时就地提示并保留内容 |
| `publish-product` | simulated | 显示发布中/成功，返回产品列表并将新产品置顶 |

## 七、必要状态

- 初始空表单
- 编辑中
- 校验失败
- 库存公开
- 发布中
- 发布成功并回填列表

## 八、数据

- 必要：产品图片、产品文案、售价。
- 可选：标签、货号、规格、颜色、库存、库存是否对外可见。
- 发布结果：产品标识、文案首行标题、封面、售价、发布时间。
- 数据仅保留当前原型会话，刷新后恢复。

## 九、影响范围

- `affected_scenes`：`["发布产品", "我的"]`
- `affected_runtime`：`["wego-app/js/routes.js"]`
- 新增独立稳定路由；具体 `route_id` 由设计阶段按仓库路由规则确定。

## 十、低风险假设

- 用户已登录且为相册主身份。
- 图片、产品文案和售价为必要信息，其他字段允许留空。
- 标签、规格、颜色以单值或逗号分隔文本录入，不展开 SKU。
- 库存对外可见默认关闭。
- 发布后回到「我的 → 产品」，不自动生成动态或分享。
- 刷新后不保留本次模拟发布结果。
