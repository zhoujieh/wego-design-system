# 微购相册快捷发布产品｜范围确认

## 一、目标

让已登录的相册主从「微购相册动态」页已有发布托盘中点击「发产品」，快速进入发布流程；发布页顶部采用类微信朋友圈的文案+图片录入方式，下方用表单补充商品属性，完成后发布为相册动态并在动态流中即时可见，同时支持从动态详情重新编辑已有信息。

## 二、本次纳入

- 复用「微购相册动态」页已有的发布托盘/悬浮入口，点击「发产品」进入独立发布页。
- 独立发布页：顶部返回、底部固定「发布」主操作。
- 页面顶部为类微信朋友圈图文区：
  - 产品名/文案：顶部自由文本输入，不使用 form 组件样式
  - 产品图片：文案下方图片网格选择，不使用 form 组件样式
- 图文区下方用表单组件补充商品属性：
  - 单值：售价、货号、重量、库存
  - 多值：规格、颜色、标签、来源（支持添加/删除多项）
- 可见范围：公开 / 私密 / 部分可见 / 不给谁看；后两项可从粉丝分组中选择。
- 必要校验：产品名/文案、产品图片缺失时用 toast 提示；售价缺失时就地提示；保留已填内容。
- 发布中/成功反馈，成功后新动态卡片置顶在微购相册动态流。
- 动态详情页对自己发布的产品动态显示「编辑」入口，回填后保存更新。
- 所有表单交互、校验、回填均为真实可点。

## 三、本次不做

- 真实图片上传、相机/相册权限、裁剪、压缩、云端传输。
- 草稿、定时发布、审核、失败重试、刷新后持久化。
- SKU 组合、分规格价格/库存、批发价。
- 商品分类、物流、售后、佣金、营销、交易设置。
- 批量/Excel 导入、平台搬家、扫码发布。
- 产品上下架、删除、批量管理、独立产品列表页。
- 发布后自动分享至微信等第三方。
- 可见范围的真实权限校验和粉丝分组后端同步。

## 四、入口

- `动态 tab → 微购相册动态页 → 发布托盘/悬浮入口 → 发产品`
- `自己发布的产品动态 → 动态详情 → 底部操作栏「编辑」→ 发布页（回填模式）`
- 发布页返回后恢复进入前页面上下文。

## 五、关键路径

1. 进入「微购相册动态」，点击发布托盘中的「发产品」。
2. 在类朋友圈图文区填写产品名/文案并选择产品图片。
3. 在下方表单填写售价、货号、规格、颜色、重量、库存、标签、来源。
4. 对规格、颜色、标签、来源按需添加多项。
5. 设置可见范围；部分可见/不给谁看选择粉丝分组。
6. 点击底部固定「发布」。
7. 必要信息缺失时就地提示并保留内容。
8. 校验通过后显示发布中/成功反馈。
9. 返回「微购相册动态」，新动态卡片显示在列表顶部。
10. 进入自己发布的动态详情，点击「编辑」。
11. 表单回填已有信息，修改后保存，返回详情并展示更新内容。

## 六、原型边界

| flow_id | mode | visible_result |
| --- | --- | --- |
| `open-quick-publish` | functional | 从微购相册动态悬浮按钮进入独立快捷发布页，返回恢复上下文 |
| `fill-product-form` | functional | 选择模拟图片并填写所有字段，多值字段支持增删 |
| `set-visibility` | functional | 切换可见范围，部分可见/不给谁看可勾选粉丝分组 |
| `validate-product-form` | functional | 必填项缺失时就地提示并保留已填内容 |
| `publish-product` | simulated | 发布中/成功反馈，返回动态首页新卡片置顶 |
| `edit-product` | simulated | 从自己动态详情进入编辑，回填并保存更新 |

## 七、必要状态

- 初始空表单
- 编辑中
- 校验失败
- 多值输入中
- 可见范围选择中
- 发布中
- 发布成功并回填动态流
- 编辑回填
- 编辑成功并更新详情

## 八、数据

- 必填：产品名、产品图片、售价。
- 选填：货号、规格（数组）、颜色（数组）、重量、库存、标签（数组）、来源（数组）、可见范围、可见分组。
- 图片：使用本地商品素材，asset_id + src + media_type。
- 粉丝分组：本地模拟 group_id + group_name。
- 发布结果：dynamic_id、product_id、name、cover、sale_price、published_at，仅当前会话保留。

## 九、影响范围

- `affected_scenes`：`["发布产品", "微购相册动态", "动态详情"]`
- `affected_runtime`：`["wego-app/js/routes.js"]`
- 新增独立稳定路由；具体 `route_id` 由设计阶段按仓库路由规则确定。

## 十、低风险假设

- 用户已登录且为相册主身份。
- 产品名、产品图片和售价为必要信息，其他字段允许留空。
- 规格、颜色、标签、来源以多值数组录入，不展开 SKU。
- 可见范围默认公开，分组数据为本地模拟。
- 发布结果刷新后不保留。
- 编辑入口只对自己发布的产品动态可见。
