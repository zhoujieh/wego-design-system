# 我的 tab 内容管理 - 范围确认

> 迭代目录：`wego-app/scenes/我的/_iterations/20260727-my-tab-content-management-我的tab内容管理/`
> 主场景：`我的`（host-tab）
> 状态：`awaiting-brief-confirmation`（待用户确认范围）
> 创建日期：2026-07-27
> 范围版本：2（新增分享主页、导航栏结构、发布入口、多视图、多选一致性）

---

## 一、迭代目标

把"我的"tab 从"身份展示+功能平铺"页升级为**相册内容管理中枢**，与动态页形成"消费-管理"双向入口。

- **核心功能一·管理相册内容**：按类型（产品 / 笔记 / 直播）管理已发布内容，支持上架/下架、编辑、分享、删除，支持多选批量操作；列表支持多视图切换（为后续扩展预留架构）。
- **核心功能二·搜索**：搜我的内容 + 我的应用/工具。
- **核心功能三·分享主页**：分享整个相册主页，导航栏固定入口，一键触发分享。
- **结构与动态页一致**：导航栏（设置/类型 tabs/分享+发布）+ 搜索栏 + 操作行（筛选/多选/视图切换）+ 内容列表，保持跨 tab 一致性。
- **现有功能保留但重组**：头像身份、会员、空间、应用、订单、个人服务全部保留，但下沉/折叠，让出视觉焦点给内容管理。

## 二、现状与原则冲突（设计决策原则对照）

| 现状 | 冲突原则 | 问题 |
| --- | --- | --- |
| 首屏首要任务是头像+会员卡 | `wego-clarity-single-primary-task` | 用户核心目标"管理内容"未在首屏出现 |
| 会员、空间、应用、订单、个人服务平铺 | `wego-clarity-information-flow` | 不同类型信息交叉，未按任务分组 |
| 应用 grid 占两行，订单 grid 占一行 | `wego-aesthetics-432-check` | 次要功能占据主流路径空间 |
| 无搜索能力 | `wego-efficiency-step-reduction` | 用户找内容只能滚动浏览 |
| 单条管理只能进二级页 | `wego-efficiency-continuous-flow` | 步骤断裂，无即时反馈 |
| 无分享主页入口 | `wego-efficiency-step-reduction` | 商家获客路径长 |
| 顶部结构与动态页不一致 | `wego-consistency-same-pattern` | 同类"主 tab"结构差异大，用户切换成本高 |

## 三、信息架构（与动态页结构对齐）

```
我的 tab（host-tab，data-bg=page）
├── 顶部吸顶栈（top-stack，背景 bg-surface）
│   ├── 导航栏 nav-row（与动态页 nav-row 一致结构）
│   │   左：设置图标按钮（navbar 左侧固定位置）
│   │   中：类型 tabs（产品 / 笔记 / 直播）
│   │   右：分享主页图标按钮 + 发布按钮（复用动态页发布托盘）
│   ├── 搜索栏（常驻吸顶，accent 强调样式，placeholder="搜索我的内容与应用"）
│   └── 操作行
│       状态筛选 segment（全部/已发布/草稿/已下架）
│       + 多选按钮
│       + 视图切换按钮（列表视图 / 网格视图，默认列表）
├── 滚动区（data-tab-scroll）
│   ├── 内容列表（多视图）
│   │   列表视图（默认）：横向卡片，封面 72 方图 + 标题 + 状态标签 + 时间 + 数据指标 + 操作菜单触发
│   │   网格视图：紧凑方图双列，封面 + 标题 + 状态标签 + 操作菜单触发
│   └── 二级入口区（下沉，弱化视觉权重，列表末尾）
│       「我买的」订单入口 cell（带待办 metric）
│       「更多服务」入口 cell（设置/钱包/收藏/卡券/提现/空间管理）
├── 多选底部操作栏（多选模式出现，固定底部）
│   全选 + 已选 N + 上架/下架 + 分享 + 删除
├── 发布托盘（复用动态页结构：发产品/发笔记/开直播/批量导入/扫一扫）
└── 发布遮罩（点击空白关闭托盘）
```

**视觉层级裁决**（基于 `wego-aesthetics-neutral-priority`）：
- 中性色背景承载内容列表
- 品牌色仅用于主动作（多选确认、上架、分享主页按钮）
- 状态色仅表达内容状态（已发布=成功色、草稿=中性、已下架=警告色）
- 留白分组：导航栏 / 搜索 / 操作行 / 内容列表 / 二级入口 五块清晰分隔

**一致性裁决**（基于 `wego-consistency-same-pattern`）：
- 导航栏结构与动态页 nav-row 一致（左固定按钮 / 中 tabs / 右操作按钮）
- 发布托盘结构与动态页一致（5 个发布选项相同）
- 搜索栏样式与动态页一致（accent 强调样式 + 图搜按钮）
- 多选模式与动态页选品车视觉一致（checkbox 位置、选择态高亮、底部操作栏样式）

## 四、纳入范围（included）

1. **导航栏**：顶部吸顶，左设置图标按钮、中类型 tabs、右分享主页图标 + 发布按钮。
2. **设置入口**：导航栏左侧固定位置，点击 toast 反馈（stub）。
3. **分享主页**：导航栏右侧固定按钮，点击触发微信分享 simulated toast，不展开多方式选择。
4. **发布入口**：导航栏右侧按钮 + 发布托盘（复用动态页 5 个发布选项），点击托盘外关闭。
5. **搜索栏**：导航栏下方常驻吸顶，输入关键词后展示"内容"+"应用"两个结果 section。
6. **内容类型 tabs**：产品 / 笔记 / 直播，默认产品，单选切换。
7. **状态筛选 segment**：全部 / 已发布 / 草稿 / 已下架，单选，默认全部。
8. **视图切换**：列表视图（默认）/ 网格视图，点击切换图标切换。
9. **内容列表 - 列表视图**：横向卡片，封面 72 方图 + 标题 + 状态标签 + 发布时间 + 数据指标（浏览/转发/选品）+ 右下角操作菜单触发。
10. **内容列表 - 网格视图**：双列方图卡片，封面 + 标题 + 状态标签 + 操作菜单触发（紧凑展示，无数据指标）。
11. **单条管理操作**：编辑（stub toast）、上架/下架（functional，状态实时切换）、分享（simulated toast）、删除（dialog 二次确认，functional）。
12. **多选模式**：点击"多选"按钮进入，两种视图下 checkbox 均出现在卡片左上角，底部出现固定操作栏，支持全选/反选、批量上架/下架、批量分享、批量删除。
13. **多选一致性**：两种视图下 checkbox 位置、选择态边框高亮、底部操作栏样式完全一致。
14. **空状态**：当某类型+某状态无内容时，展示空状态插画+引导文案。
15. **二级入口下沉**：
    - 「我买的」订单入口：一行 cell，右侧带待办 metric（待付款/已发货等合计）。
    - 「更多服务」入口：一行 cell，进入二级页 stub（设置/钱包/收藏/卡券/提现/空间管理）。
16. **空间使用**：从顶部会员卡下沉到「更多服务」二级页，不在 tab 内常驻。
17. **身份条精简**：头像压缩到 40，会员卡取消独立卡片，VIP/角色 tag 内联到身份条，续费入口降级为身份条右侧 link 按钮。
18. **身份条位置**：作为列表首条之上的一行精简展示，不进入吸顶栈（避免和管理区视觉竞争）。

## 五、排除范围（excluded）

1. 不做真实后端联动：编辑、上架/下架、删除、分享、批量操作、分享主页均使用本地数据模拟反馈。
2. 不做真实搜索后端：搜索使用本地数据模糊匹配。
3. 不做编辑页真实表单：点击"编辑"toast 反馈。
4. 不做订单二级页真实数据：点击「我买的」toast 反馈。
5. 不做个人服务二级页真实内容：点击「更多服务」toast 反馈。
6. 不做跨会话或刷新后内容状态持久化：本期仅在当前原型会话内模拟。
7. 不做内容详情页：内容卡片点击仅展示操作菜单（详情已在动态 tab 完成）。
8. 不做新增内容真实流程：发布托盘选项仅 toast 反馈（真实发布由动态 tab 承担）。
9. 不做复杂数据指标看板：卡片仅展示浏览/转发/选品三个基础数字。
10. 不做应用 grid 常驻：应用入口收进搜索结果或「更多服务」二级页。
11. 不做瀑布流视图：本期视图切换仅列表/网格两种，瀑布流预留架构但本期不实现。
12. 不做分享方式多选展开：分享主页只触发微信分享 simulated，不展示"微信/二维码/复制链接"多方式面板。
13. 不做购物车浮动入口：购物车能力属于动态 tab，我的 tab 不重复展示。

## 七、关键路径（critical_paths）

1. 进入我的 tab → 看到导航栏（设置/类型 tabs/分享+发布）+ 搜索栏 + 操作行 + 内容列表（默认产品/全部/列表视图）。
2. 切换类型 tab（产品→笔记→直播） → 列表实时更新对应类型内容。
3. 切换状态筛选（全部→已发布→草稿→已下架） → 列表按状态过滤。
4. 切换视图（列表→网格） → 列表样式切换，内容保持。
5. 点击搜索 → 输入"连衣裙" → 看到"内容"section（匹配的产品/笔记/直播）+ "应用"section（匹配的工具，如"商品管理"） → 点击结果 toast 反馈。
6. 点击单条卡片操作菜单 → 选择"下架" → 状态标签实时变为"已下架"，列表保持位置 → toast 反馈。
7. 点击"多选"按钮 → 进入多选模式 → 两种视图下 checkbox 均出现 → 勾选 3 条 → 底部操作栏出现"已选 3" → 点击"删除" → dialog 二次确认 → 确认后列表减少 3 条 → toast 反馈。
8. 切换到网格视图 → 进入多选模式 → checkbox 位置和选择态视觉与列表视图一致 → 批量操作行为一致。
9. 点击导航栏「分享主页」→ toast 反馈"已分享相册主页"（simulated）。
10. 点击导航栏「发布」→ 打开发布托盘 → 点击"发产品" → toast 反馈（stub）→ 点击托盘外关闭。
11. 点击导航栏「设置」→ toast 反馈"已进入设置"（stub）。
12. 点击「我买的」入口 → toast 反馈（stub）。
13. 点击「更多服务」入口 → toast 反馈（stub）。
14. 点击身份条「去续费」→ toast 反馈（stub）。

## 九、业务状态（states）

- `my-tab-default`：默认进入，产品 tab + 全部状态 + 列表视图，展示已发布内容列表。
- `type-tab-switched`：切换类型 tab 后，列表更新。
- `status-filtered`：状态筛选后，列表按状态过滤。
- `view-mode-switched`：视图切换后，列表样式变化，内容和多选状态保持。
- `search-active`：搜索输入态，展示内容+应用结果 section。
- `single-managed`：单条管理操作后，列表实时反馈（状态切换或移除）。
- `multi-select-active`：多选模式，两种视图下 checkbox 出现，底部操作栏出现，可批量操作。
- `batch-managed`：批量操作后，列表实时反馈。
- `publish-dock-open`：发布托盘打开，遮罩出现，点击托盘外关闭。
- `empty-state-visible`：某类型+某状态无内容时，展示空状态。
- `secondary-entry-feedback`：点击二级入口后 toast 反馈。

## 十、数据合同（data_contract）

### `my_content`（我的内容列表）
- `content_id`：内容唯一标识
- `type`：`product` | `note` | `live`（产品/笔记/直播）
- `title`：内容标题
- `cover`：封面图 URL
- `published_at`：发布时间（相对时间，如"3天前"）
- `status`：`published` | `draft` | `offline`（已发布/草稿/已下架）
- `stats`：`{ views, forwards, selections }`（浏览/转发/选品数）

### `search_result`（搜索结果）
- `content_items`：匹配的内容列表（结构同 my_content）
- `app_items`：匹配的应用列表（`{ name, asset }`，复用现有应用图标资产）

### `selection_state`（多选状态）
- `selected_ids`：已勾选的内容 id 数组
- `all_selectable_ids`：当前列表所有可选 id
- `is_all_selected`：是否全选
- `view_mode`：当前视图模式（`list` | `grid`），多选状态在视图切换时保持

### `view_mode`（视图模式）
- `current`：`list` | `grid`，默认 `list`
- `persistence`：会话内有效，不做持久化

### `persistence`
- 内容管理状态（上下架/删除）、视图模式、多选状态均会话内有效，不做持久化。

## 十一、低风险假设（assumptions）

1. 假设当前商家已登录，使用 `WEGO_PROTOTYPE_DB.currentUser` 数据填充身份条。
2. 假设内容列表使用本地模拟数据（30-50 条覆盖三种类型和四种状态）。
3. 假设多选模式无上限（实际可加 50 条上限，本期不实现）。
4. 假设删除二次确认使用 dialog 组件（高风险阻断）。
5. 假设编辑/分享/订单/个人服务/续费/设置等二级页本期 stub，不进入真实页面。
6. 假设搜索为本地模糊匹配（标题包含关键词），不做分词和排序。
7. 假设应用搜索结果复用 `mySceneAllApps` 数据，匹配应用名称。
8. 假设分享主页为微信分享 simulated，不展示多方式选择面板。
9. 假设发布托盘 5 个选项与动态页完全一致（发产品/发笔记/开直播/批量导入/扫一扫）。
10. 假设视图切换本期仅列表/网格两种，瀑布流等后续视图预留架构但不实现。
11. 假设导航栏样式遵循动态页 nav-row 结构，但配色和按钮样式由 wego-design 按设计系统决定。

## 十五、与动态页的结构对照（一致性说明）

| 区域 | 动态页 | 我的 tab | 一致性 |
| --- | --- | --- | --- |
| 导航栏左 | 空 | 设置图标 | 结构一致（左固定按钮） |
| 导航栏中 | 关注/推荐/上新 tabs | 产品/笔记/直播 tabs | 结构一致（类型 tabs） |
| 导航栏右 | 发布按钮 | 分享主页 + 发布按钮 | 结构一致（右侧操作按钮组） |
| 搜索栏 | accent 强调 + 图搜按钮 | accent 强调 + 图搜按钮 | 样式一致 |
| 操作行 | 筛选 tags | 状态筛选 segment + 多选 + 视图切换 | 结构对应（管理场景扩展） |
| 内容列表 | 瀑布流双列 | 列表/网格双视图 | 消费 vs 管理差异 |
| 多选 | 选品车（购物车 FAB） | 多选模式（底部操作栏） | 管理场景特有 |
| 发布托盘 | 5 选项 | 5 选项（相同） | 完全一致 |
| 二级入口 | 无 | 我买的 + 更多服务 | 管理场景特有 |
