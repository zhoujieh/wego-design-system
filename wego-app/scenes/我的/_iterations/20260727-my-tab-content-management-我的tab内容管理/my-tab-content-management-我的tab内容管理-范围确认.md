## 一、迭代目标

重构「我的」tab 信息架构，聚焦两个核心任务：
1. **管理相册内容**：按类型（产品/笔记/直播，后续扩展）管理已发布内容，支持列表/网格视图切换。
2. **分享主页**：导航栏右侧固定入口，一键触发分享。

顶部区域紧凑分组（4行），保证内容列表优先露出。整合用户数据资产入口、核心功能入口与购物车入口，禁止重复入口。整体视觉克制收拢。

## 二、信息架构（v3，紧凑4行）

```
我的 tab（host-tab）
├── 顶部吸顶栈
│   └── 导航栏
│       左：个人信息（头像+昵称+认证+会员/角色标签+▾切换指示），整区域点击切换相册（本期不下钻）
│       右：设置 ⚙ + 分享主页 ↗（按组件规范只放两个入口）
├── 滚动顶部区（紧凑4行）
│   ① 会员栏（独立1行卡片）：等级 + 到期时间 + 云空间用量（进度条+已用/总量）
│   ② 数据资产横滑：我买的（第一位,品牌色强调,有订单待办才显示）+ 粉丝/好友/代理/访客/员工/钱包/卡券/收藏
│   ③ 常用应用横滑：进入主页(固定) | 二维码(固定) ‖ 最近应用... + 全部
│   └── （分隔线区隔固定入口与最近应用）
├── 列表区（吸顶）
│   ├── 类型 tabs（产品/笔记/直播，支持扩展）紧贴列表
│   ├── 工具行：内联弱化搜索 + 筛选按钮(只入口) + 视图切换（最右侧）
│   └── 内容列表（卡片不显示状态标签，底部无额外内容）
│       列表视图：横向卡片，封面 + 标题 + 时间 + 数据指标 + 操作菜单
│       网格视图：紧凑方图双列
├── 悬浮层
│   ├── 购物车 FAB（有内容才显示，复用动态页组件，带数量角标）
│   └── 发布 FAB（复用动态页发布托盘组件，点击展开 dock）
└── 发布托盘 dock（发产品/发笔记/开直播/批量导入/扫一扫）
```

## 三、纳入范围（included）

1. **导航栏**：左侧个人信息（切换相册入口，本期不下钻）；右侧设置+分享主页（只两个入口）。
2. **会员栏**：独立1行卡片，显示等级+到期时间+云空间用量。
3. **数据资产横滑**：8入口（我买的+粉丝/好友/代理/访客/员工/钱包/卡券/收藏），我买的有待办才显示。
4. **常用应用横滑**：固定2入口（进入主页、二维码）+ 最近应用 + 全部。
5. **类型tabs**：产品/笔记/直播，紧贴列表，支持后续扩展。
6. **工具行**：内联弱化搜索 + 筛选按钮(只入口) + 视图切换，随tab联动。
7. **内容列表**：卡片不显示状态标签，列表/网格视图 per-tab 独立记忆。
8. **购物车FAB**：有内容才显示，复用动态页组件。
9. **发布FAB**：复用动态页发布托盘组件。

- 导航栏右侧：设置 ⚙ + 分享主页 ↗
- 会员中心卡片：进入会员中心（stub）
- 数据资产横滑：我买的（有待办才显示）/ 粉丝/好友/代理/访客/员工/钱包/卡券/收藏（stub）

## 六、关键路径（critical_paths）

1. 进入我的tab → 顶部紧凑4行 → 直接看到类型tabs+内容列表
2. 切换类型tab → 工具行（搜索placeholder、筛选标题、视图模式）联动
3. 切换视图 → 当前tab列表/网格切换并per-tab记忆
4. 点击发布FAB → 弹出发布托盘 → 选择发布动作（stub）
5. 购物车有内容 → FAB显示 → 点击进入购物车（复用动态页组件）
6. 点击常用应用「进入主页」/「二维码」→ stub反馈
7. 横滑数据资产 → 点击对应入口 → stub反馈
8. 点击会员中心卡片 → stub反馈
9. 点击导航栏分享主页 → stub反馈
10. 点击导航栏左侧个人信息 → 切换相册反馈（stub，不下钻）
